# Orra

[English](README.md) | 简体中文

Orra 是一款开源的 Mac 语音输入 App。按住一个键说话，松开后，文字就会出现在你正在输入的 App 里。语音在你自己的 Mac 上转成文字，从不经过服务器。

Orra 目前是早期预览版。难免有不完善的地方，设计也还会调整。

## 功能

- 支持中文、英文，以及一句话里中英混说，可以输入到任何能打字的 App。
- 用 Qwen3-ASR 1.7B 模型在你的 Mac 上把语音转成文字，你说的话不会离开这台 Mac。
- 个人词库最多可以放 100 个名字和术语，Orra 会按你的写法输出。打开学习功能后，Orra 还会记住你在听写后改正过的词。
- 屏幕底部的小横条表示 Orra 已就绪，说话时会显示你的音量。
- 可以在 App 里直接更新。

## 下载

在[最新版本](https://github.com/db-ol/Orra/releases/latest)页面下载 `Orra-<版本号>.dmg`，打开后把 Orra 拖进“应用程序”。

- 需要搭载 Apple 芯片、macOS 15.6 或更高版本的 Mac，以及大约 3 GB 的可用空间。
- Orra 使用 Developer ID 签名并经过苹果公证，打开时不会出现安全警告。
- Orra 不在 Mac App Store 上架，因为 App Store 的沙盒不允许 App 在其他 App 里监听按键或粘贴文字。

## 开始使用

1. 打开 Orra，欢迎窗口会带你完成三步：
   - **下载语音模型**，2.47 GB，只需一次。
   - **允许使用麦克风。**
   - **允许辅助功能**，Orra 需要它来识别说话键和粘贴文字。
2. 按住说话键（默认是右 Control，可以更换）说话，松开后文字会出现在光标所在的位置。
3. Orra 在菜单栏和程序坞里，其他功能都在它的菜单和设置里。

## 使用说明

- **说话键。** 在菜单的“说话键”或“设置 → 通用”里，可以选择右 Control、右 Option、右 Command 或 fn（地球仪键）。
- **个人词库。** 在“设置 → 个人词库”里添加你常用的词和名字，Orra 每次听写都会把它们提供给语音模型。在测试语音上，这些词的正确率中文从约 84% 提高到 99%，英文从 83% 提高到 96%，而且没说到的词几乎不会被凭空加进来。
- **从你的修改中学习。** 在“个人词库”里打开“从我的修改中学习”。听写后你改正了一个听错的词，Orra 会把正确的写法加入个人词库，并弹出提示，你可以撤销。它在 macOS 能读取文字的 App 里有效，比如备忘录、邮件和 Safari。在其他 App 里，可以拷贝这个词，再从 Orra 的菜单里添加。
- **麦克风。** Orra 默认使用系统的输入设备，也可以在“麦克风”里选择别的。MacBook 合上盖子时内置麦克风会关闭，这时请选择其他麦克风，比如摄像头上的。
- **提示音、指示条、小横条和程序坞图标。** 都可以在“设置 → 通用”里关闭。
- **界面语言。** Orra 的菜单和窗口有英文和简体中文，默认跟随你的 Mac。要单独给 Orra 设置语言，请到“系统设置 → 通用 → 语言与地区 → App”。
- **更新。** 在菜单里选择“检查更新…”，或者在“设置 → 关于”里让 Orra 自动检查。

## 隐私

Orra 在你的 Mac 上把语音转成文字，从不把录音或文字发送到任何地方。它没有账号、没有统计，也没有自己的服务器。粘贴的文字只留在这台 Mac 的剪贴板上，所以“通用剪贴板”不会把它同步到你的其他设备。

**从你的修改中学习**默认关闭。打开后，每次粘贴后的 3 分钟内，只要你还在那个输入框里，Orra 会通过 macOS 辅助功能每秒读取一次它刚粘贴进去的那个输入框的文字。它最多读取 20,000 个字符，文字只在这几分钟里保存在内存中，从不写到任何地方。它从不读取密码框，也不读取开启了“安全输入”的 App。它只保存词对，比如“克劳德”和“Claude”，以及每对出现的次数和时间，存放在 ~/Library/Application Support/io.github.db-ol.Orra/corrections.json，只出现过一次的词对一周后会被删除。连续三位以上的数字，比如验证码、金额和年份，从不保存。Orra 从不修改听写出来的文字本身。在设置里点“清除学到的修改”会删除所有词对。

**Orra 只在两种情况下联网。**

- **下载语音模型**，只在你选择“下载语音模型”之后。它从 Hugging Face（huggingface.co）下载六个文件，共 2.47 GB。如果连不上 Hugging Face，比如在中国大陆，Orra 会依次尝试 ModelScope（modelscope.cn）和 hf-mirror.com，它们提供相同的文件。hf-mirror.com 会把最大的权重文件交给 Hugging Face 自己的服务器下载，在中国大陆以外，它会把所有请求都转到 huggingface.co。使用这些文件之前，Orra 会用写在源代码里的数值核对每个文件的大小和 SHA-256 校验值，所以镜像站无法篡改模型。文件存放在 ~/Library/Application Support/io.github.db-ol.Orra/Models，不会被时间机器备份。
- **检查更新**，只在你允许之后。Orra 第二次启动时会问你是否自动检查，也可以在“设置 → 关于”里更改。检查时，Orra 大约每天读取一次 https://github.com/db-ol/Orra/releases/latest/download/appcast.xml。每次更新都要你同意后才会安装，而且只安装用本项目更新密钥签名的更新和更新清单。

在你允许检查更新之前，启动 Orra 从不联网。和所有下载一样，这些服务能看到你的 IP 地址。检查更新时还会看到 Orra 的版本号，以及和所有网页请求一样带上的偏好语言。Orra 不发送账号、令牌或 Cookie，也不发送任何其他关于你的 Mac 的信息。

要删除模型，请先退出 Orra，再删除上面的 Models 文件夹。如果 ~/Library/Caches/qwen3-speech 里有其他 App 留下的副本，也请一并删除，否则 Orra 会从那里重新安装模型。详情见 docs/model-download.md。
