# es-english-fillers (6 clips)

Spanish sentences with an English filler, um or uh, at the start or in the middle, for the
English filler rule on Spanish text. Samantha, the English voice, says the filler and Paulina
the rest, joined into one clip: their `say` is a list of [voice, text] parts. The reference
leaves the filler out, as the English filler rule would. When the rule skips Spanish text, as it
did when this set was written, a filler the model writes stays in the text. en_um_6 is short
English (Um, okay.), which the Spanish pair counted as Spanish when this set was written, so
Orra kept its Um.

No native speaker has read the Spanish text of this set yet. Until one has, its references, its
accepted spellings and every result on it are not confirmed by a native reader.
