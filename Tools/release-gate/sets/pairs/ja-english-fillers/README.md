# ja-english-fillers (6 clips)

Japanese sentences with an English filler, um or uh, at the start or in the middle, for the
English filler rule on Japanese text. Samantha, the English voice, says the filler and Kyoko the
rest, joined into one clip: their `say` is a list of [voice, text] parts. The reference leaves
the filler out, as the English filler rule would. When the rule skips Japanese text, as it did
when this set was written, a filler the model writes stays in the text. en_uh_6 is short English
(Uh, sure.), which the rule already takes with the Japanese pair, since Latin text too short to
judge counts as English there.

No native speaker has read the Japanese text of this set yet. Until one has, its references, its
accepted spellings and every result on it are not confirmed by a native reader.
