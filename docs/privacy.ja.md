# Orraのプライバシー

[English](privacy.md) · [简体中文](privacy.zh-CN.md) · 日本語 · [Español](privacy.es.md)

[README](../README.ja.md)に簡単な概要があります。このページでは詳細を説明します。

Orraはお使いのMac上で音声をテキストに変換し、録音やそのテキストをどこにも送信しません。アカウントも、利用状況の解析も、独自のサーバもありません。ペーストするテキストはこのMacのクリップボードにだけ置かれるため、ユニバーサルクリップボードでほかのデバイスに渡ることはありません。“最後の音声入力をコピー”やライブキャプションのコピー機能でコピーしたテキストも同様です。キャプションの行を選択してCommand Cでコピーした場合は、ほかのアプリと同じように通常のクリップボードに置かれます。

**修正からの学習**は、オンにするまではオフです。オンの間、Orraはペーストするたびに、ペーストしたばかりのフィールドのテキストをmacOSのアクセシビリティ機能を通じて1秒に1回読み取ります。読み取るのはペースト後の最大3分間で、そのフィールドにいる間だけです。読み取る量は最大20,000文字で、テキストはその数分間だけメモリに保持し、どこにも書き込みません。パスワードフィールドや、セキュア入力が有効なアプリは読み取らず、Orra自身のウインドウも読み取りません。保存するのは“奥拉”と“Orra”のような単語のペアと、それぞれを見た回数と日時だけで、保存先は~/Library/Application Support/io.github.db-ol.Orra/corrections.jsonです。1回しか見ていないペアは1週間後に削除します。コード、金額、年など、3桁以上続く数字は保存しません。Orraが音声入力のテキストを変更するのは、保存したペアの誤認識の表記が現れた箇所だけです。設定の“学習した修正を消去”ですべてのペアを削除できます。

**画面上の名前を使用**は、オンにするまではオフです。オンの間、音声入力を開始するたびに、OrraはmacOSのアクセシビリティ機能を通じて、音声入力先のフィールドでカーソルより前にある最大1,000文字と、そのウインドウのタイトルを読み取ります。フィールドの一部だけを渡せないアプリでは、フィールドが20,000文字以下の場合に限ってフィールド全体を読み取り、カーソルより前の最後の1,000文字だけを残します。カーソルの位置を伝えないフィールドからは、ウインドウのタイトルだけを使います。パスワードフィールド、パスワードマネージャ（1Password、Bitwarden、KeePassXC、Appleの“パスワード”と“キーチェーンアクセス”）、セキュア入力が有効なアプリは読み取らず、Orra自身のウインドウも読み取りません。そのテキストから最大40個の名前とまれな単語を取り出して、お使いのMac上の音声認識モデルに渡します。テキストそのものは渡しません。テキストと名前はその音声入力の間だけメモリに保持し、保存することもログに記録することもありません。

**会議通訳**では、キャプションと、音声サンプルで話した言葉をメモリ上にだけ保持します。キャプションはOrraを終了するまで残るので、会議のあとでもコピーできます。音声サンプルもメモリ上にだけ保持しますが、“自分の声を記憶”をオンにした場合は例外です（オンにするまではオフです）。テキストや音声をログに記録することはありません。

**Orraがインターネットを使うのは、指示されたモデルのダウンロードとアップデートの確認だけです。**

- **音声認識モデル**は、“音声認識モデルをダウンロード”か、ようこそウインドウの“モデルをダウンロード”を選択したあとにだけダウンロードします。6個のファイル（合計2.47 GB）をHugging Face（huggingface.co）から取得します。中国本土からなど、Hugging Faceに接続できない場合は、同じファイルを提供しているModelScope（modelscope.cn）、hf-mirror.comの順に試します。OrraはすべてのファイルのサイズとSHA-256ハッシュを、ソースコードに書かれた値と照合するため、ミラーがモデルを改ざんすることはできません。ファイルは~/Library/Application Support/io.github.db-ol.Orra/Modelsに保存され、Time Machineのバックアップからは除外されます。
- **整文モデル**は、ようこそウインドウで“モデルをダウンロード”か“整文モデルをダウンロード”をクリックしたとき（ようこそウインドウがこれらを表示するのは、メモリが16 GB以上のMacを使う新しいユーザの場合か、整文がオンの場合です）、設定で“テキストを整える”か“翻訳”をオンにしてダウンロードに同意したとき、または“ライブキャプション”ウインドウが“訳文”か“両方”を表示しているときに“ダウンロード”をクリックしてダウンロードに同意したとき（ダウンロードに失敗したあと、そこで“やり直す”をクリックしたときも含みます）にだけダウンロードします。mlx-community/Qwen3.5-4B-4bitの4個のファイル（合計3.05 GB）を同じサーバから取得し、同じ方法で照合して、Modelsの中にある専用のフォルダに保存します。“ライブキャプション”で同意したダウンロードによって、“テキストを整える”や“翻訳”がオンになることはありません。ダウンロードが終わる前にキャプションをオフにすると、ダウンロードは停止します。ただし、その時点で“テキストを整える”か“翻訳”がモデルを必要としている場合は停止しません。
- **音声合成モデル**は、“翻訳を相手に読み上げる”のためにダウンロードを開始したときにだけダウンロードします。Qwen3-TTS（約2 GB）をHugging Faceまたはhf-mirror.comから取得し、同じ方法で照合します。
- **アップデートの確認**は、許可したあとにだけ行います。2回目の起動時に、自動的に確認するかどうかをOrraが尋ねます。この設定は“設定”＞“情報”でも変更できます。確認では、1日に1回程度<https://github.com/db-ol/Orra/releases/latest/download/appcast.xml>を読み込みます。Orraがアップデートをインストールするのは、毎回あなたが選択したときだけで、しかもアップデートとそのフィードがプロジェクトのアップデート用の鍵で署名されている場合に限ります。

モデルはお使いのMac上で動作し、インターネットに接続することはありません。アップデートの確認を許可するまで、Orraを起動してもネットワークに接続することはありません。ほかのダウンロードと同じく、これらのサービスからはあなたのIPアドレスが見えます。アップデートの確認では、さらにOrraのバージョンと、ほかのWebリクエストと同じく優先する言語も伝わります。Orraはアカウント、トークン、Cookieを送信せず、Macに関するそれ以外の情報も送信しません。サーバと照合の詳細は[docs/model-download.md](model-download.md)（英語）で説明しています。

**問題を報告**は、お使いのMac上にテキストファイルを作成します。内容は、Orraのバージョン、設定、権限の状態、Macの機種、チップ、メモリ、macOSのバージョンと言語、マイクの名前、直近1時間のOrra自身のログ、直近7日間のクラッシュレポートです。音声入力したテキスト、音声、クリップボード、用語集、学習した単語は含みません。ホームフォルダのパス、アカウント名、フルネーム、コンピュータ名は取り除かれます。Orra自身は何も送信しません。ブラウザでGitHubのページを開くだけで、ファイルがGitHubに届くのは、あなたが添付した場合だけです。

モデルを削除するには、Orraを終了してから上記のModelsフォルダを削除します。整文モデルだけを削除するには、先に整文と翻訳をオフにしてから、Modelsフォルダの中にあるQwen3.5-4B-4bit-0e7ffd5cフォルダを削除します。~/Library/Caches/qwen3-speechにほかのアプリのコピーがある場合は、それも削除してください。削除しないと、Orraはそこからモデルを再びインストールします。
