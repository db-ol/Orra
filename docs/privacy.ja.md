# Orraのプライバシー

[English](privacy.md) · [简体中文](privacy.zh-CN.md) · 日本語 · [Español](privacy.es.md)

[README](../README.ja.md)に簡単な概要があります。このページでは詳細を説明します。

Orraはお使いのMac上で音声をテキストに変換し、録音やそのテキストをどこにも送信しません。アカウントも、利用状況の解析も、独自のサーバもありません。ペーストするテキストはこのMacのクリップボードにだけ置かれるため、ユニバーサルクリップボードでほかのデバイスに渡ることはありません。“最後の音声入力をコピー”やライブキャプションのコピー機能でコピーしたテキストも同様です。キャプションの行を選択してCommand Cでコピーした場合は、ほかのアプリと同じように通常のクリップボードに置かれます。

**修正からの学習**は、オンにするまではオフです。オンの間、Orraはペーストするたびに、ペーストしたばかりのフィールドのテキストをmacOSのアクセシビリティ機能を通じて1秒に1回読み取ります。読み取るのはペースト後の最大3分間で、そのフィールドにいる間だけです。読み取る量は最大20,000文字で、テキストはその数分間だけメモリに保持し、どこにも書き込みません。パスワードフィールドや、セキュア入力が有効なアプリは読み取らず、Orra自身のウインドウも読み取りません。保存するのは“奥拉”と“Orra”のような単語のペアと、それぞれを見た回数と日時だけで、保存先は~/Library/Application Support/io.github.db-ol.Orra/corrections.jsonです。1回しか見ていないペアは1週間後に削除します。コード、金額、年など、3桁以上続く数字は保存しません。Orraが音声入力のテキストを変更するのは、保存したペアの誤認識の表記が現れた箇所だけです。設定の“学習した修正を消去”ですべてのペアを削除できます。

**画面上の名前を使用**は、オンにするまではオフです。オンの間、音声入力を開始するたびに、OrraはmacOSのアクセシビリティ機能を通じて、音声入力先のフィールドでカーソルより前にある最大1,000文字と、そのウインドウのタイトルを読み取ります。フィールドの一部だけを渡せないアプリでは、フィールドが20,000文字以下の場合に限ってフィールド全体を読み取り、カーソルより前の最後の1,000文字だけを残します。カーソルの位置を伝えないフィールドからは、ウインドウのタイトルだけを使います。パスワードフィールド、パスワードマネージャ（1Password、Bitwarden、KeePassXC、Appleの“パスワード”と“キーチェーンアクセス”）、セキュア入力が有効なアプリは読み取らず、Orra自身のウインドウも読み取りません。そのテキストから最大40個の名前とまれな単語を取り出して、お使いのMac上の音声認識モデルに渡します。テキストそのものは渡しません。テキストと名前はその音声入力の間だけメモリに保持し、保存することもログに記録することもありません。

**会議通訳**では、キャプションと、音声サンプルで話した言葉をメモリ上にだけ保持します。キャプションはOrraを終了するまで残るので、会議のあとでもコピーできます。音声サンプルもメモリ上にだけ保持しますが、“自分の声を記憶”をオンにした場合は例外です（オンにするまではオフです）。テキストや音声をログに記録することはありません。

**プロジェクト**はプレビュー版の機能で、“設定”＞“プロジェクト”でオンにするまではオフです。

- **読み取るもの。** 選んだ“メール”のメールボックスにある、選んだ期間（変更しなければ過去90日間）に受信したメールと、プロジェクトに追加したフォルダ内のファイルです。選ぶまではすべてのアカウントの受信と送信済みにチェックが入っていますが、“メールの読み取りを開始”をクリックするまでは何も読み取りません。OrraはAppleイベントでメールを読み取り、macOSがその許可を求めるのは、“設定”＞“プロジェクト”で“メール”へのアクセスを許可…をクリックしたときだけです。“メール”が開いているときにだけ読み取り、“メール”を自分で開くことも、“メール”がディスクに保存しているファイルを読むこともありません。また、自分が送信したメールを見分けるために、“メール”のアカウントの名前とアドレスを読み取ります。読み取ったメールからは、PDF、Word、RTF、OpenDocument、Markdown、プレーンテキスト、CSV、カレンダーの各形式の添付ファイルのテキストを取り出します。上限は添付ファイルごとに10 MBで、テキストは64 KBまでです。フォルダ内では、ダウンロードされていないiCloud Driveのファイルなど、このMacにないファイルをスキップするため、macOSがそのために何かをダウンロードすることはありません。ホームフォルダ、ディスク全体、“メール”のデータは、追加しても読み取りません。
- **処理の内容。** Orraはルールで新しいメールをプロジェクトに振り分け、“プロジェクト”ウインドウが開いている間は、ルールで決まらないメールをMac上の整文モデルが振り分け、Orraが提案するプロジェクトに名前を付けます。“説明する”をクリックすると、モデルはプロジェクトのファイル、添付ファイル、以前のメールを出典としてメールを説明し、返信の下書きを作成します。モデルはツールを持たず、リンクを開くことも、何かを実行することも、“メール”で操作することもできません。メール、添付ファイル、ファイルが読み手から隠しているテキストや、メールや添付ファイルの中でアシスタントに語りかける行がモデルに渡ることはなく、ウインドウがそれを警告します。“プロジェクト”で読んだり、書いたり、話したりした内容を、Orraがどこかに送信することはありません。
- **行わないこと。** メールを送信、移動、削除、転送することはなく、メールを読み取っても既読にはなりません。送信ボタンはありません。“メール”で返信を開くをクリックすると、Orraは“メール”に返信ウインドウを開くよう依頼し、下書きをこのMacのクリップボードに置きます。ペーストするのはあなたです。音声入力したテキストと同じく、下書きはユニバーサルクリップボードに渡らず、クリップボードマネージャがスキップするように印が付きます。メールとモデルが書いた内容はプレーンテキストでだけ表示し、HTMLも画像も開けるリンクもないため、Orraでメールを読んでもインターネットから何かを読み込むことはありません。フォルダ内のものを書き込んだり、移動したり、削除したりすることもありません。
- **保存するもの。** ~/Library/Application Support/io.github.db-ol.Orra/Projectsに保存し、このフォルダを開いたり中のファイルを読んだりできるのはあなただけです。プロジェクトとその名前、説明、フォルダ、人物、ドメイン、ルール、リンクしたメールボックスはprojects.jsonに保存します。表示しないことにしたプロジェクトの候補もハッシュとしてここに保存しますが、アドレスやメールの言葉は含みません。Time Machineはほかのファイルと同じようにこのファイルをバックアップします。それ以外はすべてその中のIndexフォルダにあり、バックアップからは除外されます。プロジェクトのフォルダ内のファイルのテキストは、ファイルがプロジェクトのフォルダからなくなるか、プロジェクトを削除するまで保存します。各メールとその添付ファイルのテキストは、説明とともに、Orraが読み取ってから最長90日間保存します。差出人、件名、プロジェクト、マーク、警告など、メールのそのほかの情報は、そのやり取りの最新のメールをOrraが読み取ってから180日間保存します。下書きと依頼した変更は、最後に変更してから30日間保存します。プロジェクト間でメールを移動した回数は180日間、削除したメールのMessage-IDのハッシュは、再び読み取らないように最長365日間保存します。ここで削除した内容はデータベース内で上書きされます。選んだメールボックスと期間は、Orraの環境設定に保存します。
- **削除。** “プロジェクト”ウインドウで“プロジェクトを削除…”を選ぶと、1つのプロジェクトをそのインデックス、メール、下書きとともに削除します。“設定”＞“プロジェクト”で“プロジェクト”のすべてのデータを削除…をクリックすると、選んだメールボックスも含めて、“プロジェクト”が保存しているものをすべて削除します。“プロジェクト”をオフにするときは、データを残すか削除するかを尋ねます。“メール”のメールと、フォルダ内のファイルはそのまま残ります。
- **ログ**には回数、時間、エラーコードだけを記録し、メールやファイルのテキスト、件名、アドレス、名前、ファイル名は記録しません。
- **ネットワーク。** “プロジェクト”がネットワークを使うことはなく、Orraがメールサーバに接続することもありません。“メール”アプリはこれまでどおりメールを受信します。“プロジェクト”が求めたメッセージの本文を“メール”がまだダウンロードしていない場合、“メール”はそのメッセージを開いたときと同じように、メールサーバから取得することがあります。“メール”で返信を開くをクリックして開いた返信ウインドウは“メール”のもので、“メール”はほかの返信と同じように、それをアカウントの下書きに保存することがあります。

**Orraがインターネットを使うのは、指示されたモデルのダウンロードとアップデートの確認だけです。**

- **音声認識モデル**は、“音声認識モデルをダウンロード”か、ようこそウインドウの“モデルをダウンロード”を選択したあとにだけダウンロードします。6個のファイル（合計2.47 GB）をHugging Face（huggingface.co）から取得します。中国本土からなど、Hugging Faceに接続できない場合は、同じファイルを提供しているModelScope（modelscope.cn）、hf-mirror.comの順に試します。OrraはすべてのファイルのサイズとSHA-256ハッシュを、ソースコードに書かれた値と照合するため、ミラーがモデルを改ざんすることはできません。ファイルは~/Library/Application Support/io.github.db-ol.Orra/Modelsに保存され、Time Machineのバックアップからは除外されます。
- **整文モデル**は、ようこそウインドウで“モデルをダウンロード”か“整文モデルをダウンロード”をクリックしたとき（ようこそウインドウがこれらを表示するのは、メモリが16 GB以上のMacを使う新しいユーザの場合か、整文がオンの場合です）、または設定で“テキストを整える”、“翻訳”、“プロジェクト”のいずれかをオンにしてダウンロードに同意したときにだけダウンロードします。mlx-community/Qwen3.5-4B-4bitの4個のファイル（合計3.05 GB）を同じサーバから取得し、同じ方法で照合して、Modelsの中にある専用のフォルダに保存します。
- **音声合成モデル**は、“翻訳を相手に読み上げる”のためにダウンロードを開始したときにだけダウンロードします。Qwen3-TTS（約2 GB）をHugging Faceまたはhf-mirror.comから取得し、同じ方法で照合します。
- **アップデートの確認**は、許可したあとにだけ行います。2回目の起動時に、自動的に確認するかどうかをOrraが尋ねます。この設定は“設定”＞“情報”でも変更できます。確認では、1日に1回程度<https://github.com/db-ol/Orra/releases/latest/download/appcast.xml>を読み込みます。Orraがアップデートをインストールするのは、毎回あなたが選択したときだけで、しかもアップデートとそのフィードがプロジェクトのアップデート用の鍵で署名されている場合に限ります。

モデルはお使いのMac上で動作し、インターネットに接続することはありません。アップデートの確認を許可するまで、Orraを起動してもネットワークに接続することはありません。ほかのダウンロードと同じく、これらのサービスからはあなたのIPアドレスが見えます。アップデートの確認では、さらにOrraのバージョンと、ほかのWebリクエストと同じく優先する言語も伝わります。Orraはアカウント、トークン、Cookieを送信せず、Macに関するそれ以外の情報も送信しません。サーバと照合の詳細は[docs/model-download.md](model-download.md)（英語）で説明しています。

**問題を報告**は、お使いのMac上にテキストファイルを作成します。内容は、Orraのバージョン、設定、権限の状態、Macの機種、チップ、メモリ、macOSのバージョンと言語、マイクの名前、直近1時間のOrra自身のログ、直近7日間のクラッシュレポートです。音声入力したテキスト、音声、クリップボード、用語集、学習した単語は含みません。“プロジェクト”については、オンかどうかと、保存しているプロジェクト、メール、ファイルの数だけを記載します。ホームフォルダのパス、アカウント名、フルネーム、コンピュータ名は取り除かれます。Orra自身は何も送信しません。ブラウザでGitHubのページを開くだけで、ファイルがGitHubに届くのは、あなたが添付した場合だけです。

モデルを削除するには、Orraを終了してから上記のModelsフォルダを削除します。整文モデルだけを削除するには、先に整文と翻訳をオフにしてから、Modelsフォルダの中にあるQwen3.5-4B-4bit-0e7ffd5cフォルダを削除します。~/Library/Caches/qwen3-speechにほかのアプリのコピーがある場合は、それも削除してください。削除しないと、Orraはそこからモデルを再びインストールします。
