# Orra 隐私说明

[English](privacy.md) · 简体中文 · [日本語](privacy.ja.md) · [Español](privacy.es.md)

[README](../README.zh-CN.md) 里是简短的概要，这里是详细说明。

Orra 在你的 Mac 上把语音转成文字，从不把录音或文字发送到任何地方。它没有账号、没有统计，也没有自己的服务器。粘贴的文字只留在这台 Mac 的剪贴板上，所以“通用剪贴板”不会把它同步到你的其他设备。用“拷贝上次听写”或实时字幕的拷贝命令拷贝的文字也一样。在字幕里选中一行再按 Command C 拷贝，则和在其他 App 里一样，会进入普通的剪贴板。

**从你的修改中学习**默认关闭。打开后，每次粘贴后的 3 分钟内，只要你还在那个输入框里，Orra 会通过 macOS 辅助功能每秒读取一次它刚粘贴进去的那个输入框的文字。它最多读取 20,000 个字符，文字只在这几分钟里保存在内存中，从不写到任何地方。它从不读取密码框，也不读取开启了“安全输入”的 App 或 Orra 自己的窗口。它只保存词对，比如“奥拉”和“Orra”，以及每对出现的次数和时间，存放在 ~/Library/Application Support/io.github.db-ol.Orra/corrections.json，只出现过一次的词对一周后会被删除。连续三位以上的数字，比如验证码、金额和年份，从不保存。Orra 只在出现已保存词对里听错的写法时修改听写出来的文字。在设置里点“清除学到的修改”会删除所有词对。

**使用屏幕上的名字**默认关闭。打开后，每次开始听写时，Orra 会通过 macOS 辅助功能读取你听写的输入框里光标前最多 1000 个字符，以及它所在窗口的标题。如果 App 不能只给出一部分文字，Orra 会在输入框不超过 20,000 个字符时读取整个输入框，只留下光标前最后 1000 个字符。不提供光标位置的输入框只用到窗口标题。它从不读取密码框和密码管理器（1Password、Bitwarden、KeePassXC、Apple 的“密码”和“钥匙串访问”），也不读取开启了“安全输入”的 App 或 Orra 自己的窗口。它从这些文字里取出最多 40 个名字和少见词，交给你 Mac 上的语音模型，从不交出文字本身。文字和名字只在这次听写期间保存在内存中，从不保存到磁盘，也不写进日志。

**会议同传**的字幕和声音样本里说的话都只保存在内存中。字幕在退出 Orra 之前一直保留，所以会议结束后仍然可以拷贝。声音样本也只保存在内存中，除非你打开“记住我的音色”，这个开关默认关闭。Orra 从不把文字或音频写进日志。

**项目**是预览版，默认关闭，在“设置 → 项目”里打开。

- **读取什么。** 你在“设置 → 项目”里选择的“邮件”邮箱和你关联到项目的邮箱中、在你选择的时间范围内收到的邮件（默认是最近 90 天），以及你添加到项目里的文件夹中的文件。在你做出选择之前，所有帐户的收件箱和已发送是勾选的。在你点按“开始读取邮件”之前，不会读取任何邮件。在此之前，Orra 只读取你在“邮件”里的帐户和邮箱的名称，好让“设置 → 项目”把它们列出来供你选择。Orra 通过 Apple 事件读取邮件，只有你在“设置 → 项目”里点按“允许访问‘邮件’…”时，macOS 才会请你允许。它只在“邮件”打开时读取，只有你点按“打开‘邮件’”时才会打开“邮件”，也从不读取“邮件”存放在磁盘上的文件。它按时间范围往回读取一个邮箱时，比如点按“开始读取邮件”之后，“项目”窗口会显示“正在读取邮件…”和已读取的封数。更改邮箱或时间范围只影响之后读取的邮件，之前保存的邮件会一直保留，直到过期或你删除它们。它还会读取你在“邮件”里各个帐户的名称和地址，用来分辨哪些邮件是你发出的。点按“解释‘邮件’中所选邮件”时，它会问“邮件”你在那里选中了哪封邮件。你为回复勾选文件时，Orra 会告诉“邮件”这些文件在这台 Mac 上的位置，由“邮件”读取并附加它们。Orra 只交给“邮件”你添加到项目的文件夹中、且“项目”已列出的文件，每个文件在请“邮件”附加之前都会再检查一次。在它读取的邮件中，它会取出 PDF、Word、Excel、PowerPoint、RTF、OpenDocument、Markdown、纯文本、CSV 和日历文件格式的附件中的文字，每个附件最大 10 MB，每个附件最多取 64 KB 文字。在你的文件夹里，它读取文档中的文字，比如 PDF、Word、Excel 和 PowerPoint 文件，用 macOS 的文字识别在这台 Mac 上识别图片和扫描的 PDF 页面中的文字，文字识别不发送也不下载任何东西，其他文件（比如图纸或压缩包）只记下文件名和所在的文件夹。它会跳过不在这台 Mac 上的文件，比如没有下载的 iCloud 云盘文件，所以 macOS 从不为它下载任何东西。即使你添加了个人文件夹、整个磁盘或“邮件” App 的本地数据文件，它也从不读取。
- **怎样处理。** Orra 用规则把每封新邮件归入项目。“项目”窗口打开时，你 Mac 上的整理模型会归类规则定不下来的邮件，并给 Orra 建议的项目起名字。你点按“解释”时，模型会先把邮件变成中英文的检索词。Orra 用邮件里的词和这些检索词搜索邮件所属项目的文件，模型再结合这些文件、你为这封邮件选的文件、附件和以前的邮件解释这封邮件，注明出处，并起草回复。你为邮件选的文件来自你添加到项目里的文件夹，Orra 只从它为这些文件夹建立的索引中读取。对于其他地方的文件，它只会提出把文件所在的文件夹添加到某个项目，这个文件夹会用于该项目的所有邮件。“待归入项目”里的邮件还会用到你各个项目文件夹中至少与它的三个检索词相符的段落。已归入项目的邮件，如果你其他项目文件夹中的段落至少与它的两个检索词相符，并且在搜索结果中排在所属项目里每一段与检索词相符的段落前面，也会用到其中最多 2 段。每段都注明所属项目，除非检查对这封邮件发出了警告，比如关于发件人、隐藏文字、付款信息，或者索要个人资料或密码。这些段落只用于解释：模型会另发一次不含这些段落的请求来写草稿，就像没有搜索过其他项目一样，Orra 还会从每份草稿中删去它能从这些段落里认出的内容，比如金额、编号、邮件地址、人名、这些项目的名称和照抄的句子。你为这封邮件选的文件也会用来写草稿，即使它在其他项目的文件夹里。邮件要你发送文件时，Orra 用规则识别英文、中文、日文和西班牙文的这类请求，并按文件名和内容，在你项目文件夹的索引中查找可能是它的文件，先找邮件所属的项目，只有检查没有对这封邮件发出警告时，才会找其他项目。“项目”不认识的发件人要文件时，会有一条警告。发件人可能是冒充的时，Orra 不提供任何文件。模型没有任何工具，不能打开链接、运行任何东西，也不能在“邮件”里做任何操作。在邮件、附件或文件中，Orra 发现的对读者隐藏的文字，以及它识别出的对助手说话的句子，都不会交给模型，窗口会提醒你。你在“项目”里读到、写下或说出的内容，Orra 自己都不会发送到任何地方。
- **从不做什么。** 它从不发送、移动、删除或转发邮件，读取邮件也不会把它标为已读。这里没有“发送”按钮。点按“在‘邮件’中打开回复”时，Orra 请“邮件”打开它的回复窗口，把你勾选的文件作为附件加进去，并把草稿放到这台 Mac 的剪贴板上，由你自己粘贴。和听写的文字一样，草稿不会同步到“通用剪贴板”，并带有让剪贴板管理工具跳过它的标记。Orra 从不自行勾选或附加文件。邮件和模型写的内容都只以纯文本显示，没有 HTML、没有图片，也没有能打开的链接，所以在 Orra 里读邮件不会从网上加载任何内容。它从不写入、移动或删除你文件夹中的任何东西。
- **保存什么**，存放在 ~/Library/Application Support/io.github.db-ol.Orra/Projects，只有你能打开这个文件夹、读取其中的文件。你的项目及其名称、描述、文件夹、联系人、域名、规则和关联的邮箱保存在 projects.json 中，其中还有你忽略的每个建议项目所依据的域名、地址、邮箱或主题词的散列值。时间机器会像备份你的其他文件一样备份它。其余内容都在其中的 Index 文件夹里，不会被时间机器备份：项目文件夹中文件的文字、从其中的图片和扫描页面识别出的文字，以及其中所有文件的文件名和所在的文件夹，保存到文件离开项目的文件夹或你移除这个项目为止。每封邮件和它附件的文字，连同它的解释，在 Orra 读取后保存 90 天。解释中保存着模型为这封邮件生成的检索词、交给模型的文件摘录（其中也可能有其他项目的文件）和这些文件所在的位置，即使文件后来离开了项目的文件夹，它们也会随解释一起保存。解释中还保存着邮件里要文件的句子，以及回复会发给的地址。你为邮件选的文件按它们在这台 Mac 上的位置保存，保存期和邮件的文字一样，直到你更改选择，或移除这些文件所在文件夹所属的项目。邮件的其余内容，比如发件人、主题、所属项目、标记和警告，在 Orra 读取这段往来中最新一封邮件后保存 180 天。草稿、你在其中输入的内容和你要求的修改，在草稿最后一次修改后保存 30 天，你的输入也算修改。草稿不会比邮件的文字保存得更久。草稿删除后，它的解释会和邮件的文字保存得一样久。你自己把邮件归入项目的次数按对方的地址和域名记录，在最后一次归入后保存 180 天。被删除邮件的 Message-ID 的散列值最多保存 365 天，以免再次读取。Orra 会在“项目”启动时以及打开期间每天一次，删除超过期限的内容，“设置 → 项目”的“数据”部分也写明了这一点。“项目”关闭期间保留的内容，会一直保存到你再次打开“项目”或删除它们为止。在这里删除的内容会在数据库中被覆盖。你选择的邮箱和时间范围保存在 Orra 的偏好设置中。你为回复勾选的文件，以及 Orra 为邮件的请求找到的文件，只保存在内存中，直到你关闭“项目”窗口。
- **删除。** 在“项目”窗口里点按“移除项目…”，会删除一个项目及其索引、邮件和草稿，以及用到它的文件的其他邮件的解释和草稿，并把它的文件从每封邮件的选择中去掉。在“设置 → 项目”里点按“删除‘项目’的所有数据…”，会删除“项目”保存的所有内容，包括你选择的邮箱。关闭“项目”时，Orra 会问你保留还是删除这些数据。“邮件”里的邮件和你文件夹中的文件都保持原样。在“项目”里归入、编辑和删除，只会改动它保存在这台 Mac 上的数据，不会改动“邮件” App 里的邮件。
- **日志**只记录次数、耗时和错误代码，从不记录邮件或文件的文字、主题、地址、姓名或文件名。
- **联网。** 除了你同意的整理模型下载，Orra 不会为“项目”发出任何网络请求。Orra 从不连接邮件服务器。“邮件” App 照常收取邮件。如果“项目”要读的邮件，“邮件”还没有下载它的内容，“邮件”可能会从邮件服务器取回它，就像你打开这封邮件时一样。点按“在‘邮件’中打开回复”打开的回复窗口属于“邮件”，“邮件”可能会像对待其他回复一样，把它连同附件存到邮件服务器上你帐户的草稿箱里，所以你附加的文件在你发送回复之前就可能到达你的邮件服务器。

**Orra 只在下载你要求的模型和检查更新时联网。**

- **语音模型**，只在你选择“下载语音模型”，或在欢迎窗口里点按“下载模型”之后：六个文件，共 2.47 GB，从 Hugging Face（huggingface.co）下载。如果连不上 Hugging Face，比如在中国大陆，Orra 会依次尝试 ModelScope（modelscope.cn）和 hf-mirror.com，它们提供相同的文件。Orra 会用写在源代码里的数值核对每个文件的大小和 SHA-256 校验值，所以镜像站无法篡改模型。文件存放在 ~/Library/Application Support/io.github.db-ol.Orra/Models，不会被时间机器备份。
- **整理模型**，只在你点按欢迎窗口里的“下载模型”或“下载整理模型”之后（欢迎窗口在内存 16 GB 及以上的 Mac 上为新用户提供，整理文字打开时也会提供），或在设置里打开“整理文字”“翻译”或“项目”并同意下载之后，或在“实时字幕”窗口显示“译文”或“双语”时点按“下载”或“继续下载”并同意下载之后（下载失败后，在那里点按“重试”也会下载）：mlx-community/Qwen3.5-4B-4bit 的四个文件，共 3.05 GB，从同样的服务器下载，用同样的方式核对，存放在 Models 里它自己的文件夹中。在“实时字幕”里同意的下载不会打开“整理文字”或“翻译”。如果你在下载完成前关闭字幕，下载会停止，除非那时“整理文字”“翻译”或“项目”需要这个模型。
- **语音合成模型**，只在你为“为对方朗读译文”开始下载之后：Qwen3-TTS，约 2 GB，从 Hugging Face 或 hf-mirror.com 下载，用同样的方式核对。
- **检查更新**，只在你允许之后。Orra 第二次启动时会问你是否自动检查，也可以在“设置 → 关于”里更改。检查时，Orra 大约每天读取一次 https://github.com/db-ol/Orra/releases/latest/download/appcast.xml。每次更新都要你同意后才会安装，而且只安装用本项目更新密钥签名的更新和更新清单。

模型都在你的 Mac 上运行，本身从不联网。在你允许检查更新之前，启动 Orra 从不联网。和所有下载一样，这些服务能看到你的 IP 地址。检查更新时还会看到 Orra 的版本号，以及和所有网页请求一样带上的偏好语言。Orra 不发送账号、令牌或 Cookie，也不发送任何其他关于你的 Mac 的信息。服务器和核对方式的详情见 [docs/model-download.md](model-download.md)（英文）。

**报告问题**会在你的 Mac 上生成一个文本文件，包括 Orra 的版本、设置和权限状态，Mac 的型号、芯片、内存、macOS 版本和语言，麦克风名称，Orra 最近一小时的日志，以及最近 7 天的崩溃报告。它不包含任何听写的文字、录音、剪贴板、个人词库或学到的词。关于“项目”，它只写明“项目”是否打开，以及其中项目、邮件和文件的数量。你的个人文件夹路径、账户名、全名和电脑名都会被去掉。Orra 自己不发送任何东西，它只是在浏览器里打开 GitHub 页面，只有你自己附上，这个文件才会到 GitHub。你自己写的内容会出现在公开的问题里，所以报告“项目”的问题时，请不要写入邮件正文、姓名、电子邮件地址，也不要附上邮件截图。

要删除模型，请先退出 Orra，再删除上面的 Models 文件夹。如果只想删除整理模型，请先关闭整理和翻译，再删除其中的 Qwen3.5-4B-4bit-0e7ffd5c 文件夹。如果 ~/Library/Caches/qwen3-speech 里有其他 App 留下的副本，也请一并删除，否则 Orra 会从那里重新安装模型。
