# Orra 隐私说明

[English](privacy.md) · 简体中文 · [日本語](privacy.ja.md) · [Español](privacy.es.md)

[README](../README.zh-CN.md) 里是简短的概要，这里是详细说明。

Orra 在你的 Mac 上把语音转成文字，从不把录音或文字发送到任何地方。它没有账号、没有统计，也没有自己的服务器。粘贴的文字只留在这台 Mac 的剪贴板上，所以“通用剪贴板”不会把它同步到你的其他设备。用“拷贝上次听写”或实时字幕的拷贝命令拷贝的文字也一样。在字幕里选中一行再按 Command C 拷贝，则和在其他 App 里一样，会进入普通的剪贴板。

**从你的修改中学习**默认关闭。打开后，每次粘贴后的 3 分钟内，只要你还在那个输入框里，Orra 会通过 macOS 辅助功能每秒读取一次它刚粘贴进去的那个输入框的文字。它最多读取 20,000 个字符，文字只在这几分钟里保存在内存中，从不写到任何地方。它从不读取密码框，也不读取开启了“安全输入”的 App 或 Orra 自己的窗口。它只保存词对，比如“奥拉”和“Orra”，以及每对出现的次数和时间，存放在 ~/Library/Application Support/io.github.db-ol.Orra/corrections.json，只出现过一次的词对一周后会被删除。连续三位以上的数字，比如验证码、金额和年份，从不保存。Orra 只在出现已保存词对里听错的写法时修改听写出来的文字。在设置里点“清除学到的修改”会删除所有词对。

**使用屏幕上的名字**默认关闭。打开后，每次开始听写时，Orra 会通过 macOS 辅助功能读取你听写的输入框里光标前最多 1000 个字符，以及它所在窗口的标题。如果 App 不能只给出一部分文字，Orra 会在输入框不超过 20,000 个字符时读取整个输入框，只留下光标前最后 1000 个字符。不提供光标位置的输入框只用到窗口标题。它从不读取密码框和密码管理器（1Password、Bitwarden、KeePassXC、Apple 的“密码”和“钥匙串访问”），也不读取开启了“安全输入”的 App 或 Orra 自己的窗口。它从这些文字里取出最多 40 个名字和少见词，交给你 Mac 上的语音模型，从不交出文字本身。文字和名字只在这次听写期间保存在内存中，从不保存到磁盘，也不写进日志。

**会议同传**的字幕和声音样本里说的话都只保存在内存中。字幕在退出 Orra 之前一直保留，所以会议结束后仍然可以拷贝。声音样本也只保存在内存中，除非你打开“记住我的音色”，这个开关默认关闭。Orra 从不把文字或音频写进日志。

**项目**是预览版，默认关闭，在“设置 → 项目”里打开。

- **读取什么。** 你选择的“邮件”邮箱中、在你选择的时间范围内收到的邮件（默认是最近 90 天），以及你添加到项目里的文件夹中的文件。在你做出选择之前，所有帐户的收件箱和已发送是勾选的，但在你点按“开始读取邮件”之前，不会读取任何邮件。Orra 通过 Apple 事件读取邮件，只有你在“设置 → 项目”里点按“允许访问‘邮件’…”时，macOS 才会请你允许。它只在“邮件”打开时读取，从不自己打开“邮件”，也从不读取“邮件”存放在磁盘上的文件。它还会读取你在“邮件”里各个帐户的名称和地址，用来分辨哪些邮件是你发出的。在它读取的邮件中，它会取出 PDF、Word、RTF、OpenDocument、Markdown、纯文本、CSV 和日历文件格式的附件中的文字，每个附件最大 10 MB，每个附件最多取 64 KB 文字。在你的文件夹里，它会跳过不在这台 Mac 上的文件，比如没有下载的 iCloud 云盘文件，所以 macOS 从不为它下载任何东西。即使你添加了个人文件夹、整个磁盘或“邮件”的数据，它也从不读取。
- **怎样处理。** Orra 用规则把每封新邮件归入项目。“项目”窗口打开时，你 Mac 上的整理模型会归类规则定不下来的邮件。你点按“解释”时，模型会结合项目文件、附件和以前的邮件解释这封邮件，注明出处，并起草回复。模型没有任何工具，不能打开链接、运行任何东西，也不能在“邮件”里做任何操作。邮件、附件或文件对读者隐藏的文字，以及邮件或附件里对助手说话的句子，从不交给模型，窗口会提醒你。你在“项目”里读到、写下或说出的内容，Orra 都不会发送到任何地方。
- **从不做什么。** 它从不发送、移动、删除或转发邮件，读取邮件也不会把它标为已读。这里没有“发送”按钮。点按“在‘邮件’中打开回复”时，Orra 请“邮件”打开它的回复窗口，并把草稿放到这台 Mac 的剪贴板上，由你自己粘贴。和听写的文字一样，草稿不会同步到“通用剪贴板”，并带有让剪贴板管理工具跳过它的标记。邮件和模型写的内容都只以纯文本显示，没有 HTML、没有图片，也没有能打开的链接，所以在 Orra 里读邮件不会从网上加载任何内容。它从不写入、移动或删除你文件夹中的任何东西。
- **保存什么**，存放在 ~/Library/Application Support/io.github.db-ol.Orra/Projects，只有你能打开这个文件夹、读取其中的文件。你的项目及其名称、描述、文件夹、人员、域名、规则和关联的邮箱保存在 projects.json 中，时间机器会像备份你的其他文件一样备份它。其余内容都在其中的 Index 文件夹里，不会被时间机器备份：项目文件夹中文件的文字，保存到文件离开项目的文件夹或你移除这个项目为止。每封邮件和它附件的文字，连同它的解释，在 Orra 读取后最多保存 90 天。邮件的其余内容，比如发件人、主题、所属项目、标记和警告，在 Orra 读取这段往来中最新一封邮件后保存 180 天。草稿和你要求的修改，在最后一次修改后保存 30 天。你在项目之间移动邮件的次数保存 180 天。被删除邮件的 Message-ID 的散列值最多保存 365 天，以免再次读取。在这里删除的内容会在数据库中被覆盖。你选择的邮箱和时间范围保存在 Orra 的偏好设置中。
- **删除。** 在“项目”窗口里点按“移除项目…”，会删除一个项目及其索引、邮件和草稿。在“设置 → 项目”里点按“删除‘项目’的所有数据…”，会删除“项目”保存的所有内容，包括你选择的邮箱。关闭“项目”时，Orra 会问你保留还是删除这些数据。“邮件”里的邮件和你文件夹中的文件都保持原样。
- **日志**只记录次数、耗时和错误代码，从不记录邮件或文件的文字、主题、地址、姓名或文件名。
- **联网。** “项目”不增加任何联网。Orra 从不连接邮件服务器。“邮件” App 照常收取邮件。如果“项目”要读的邮件，“邮件”还没有下载它的内容，“邮件”可能会从邮件服务器取回它，就像你打开这封邮件时一样。点按“在‘邮件’中打开回复”打开的回复窗口属于“邮件”，“邮件”可能会像对待其他回复一样，把它存到你帐户的草稿箱里。

**Orra 只在下载你要求的模型和检查更新时联网。**

- **语音模型**，只在你选择“下载语音模型”，或在欢迎窗口里点按“下载模型”之后：六个文件，共 2.47 GB，从 Hugging Face（huggingface.co）下载。如果连不上 Hugging Face，比如在中国大陆，Orra 会依次尝试 ModelScope（modelscope.cn）和 hf-mirror.com，它们提供相同的文件。Orra 会用写在源代码里的数值核对每个文件的大小和 SHA-256 校验值，所以镜像站无法篡改模型。文件存放在 ~/Library/Application Support/io.github.db-ol.Orra/Models，不会被时间机器备份。
- **整理模型**，只在你点按欢迎窗口里的“下载模型”或“下载整理模型”之后（欢迎窗口在内存 16 GB 及以上的 Mac 上为新用户提供，整理文字打开时也会提供），或在设置里打开“整理文字”“翻译”或“项目”并同意下载之后：mlx-community/Qwen3.5-4B-4bit 的四个文件，共 3.05 GB，从同样的服务器下载，用同样的方式核对，存放在 Models 里它自己的文件夹中。
- **语音合成模型**，只在你为“为对方朗读译文”开始下载之后：Qwen3-TTS，约 2 GB，从 Hugging Face 或 hf-mirror.com 下载，用同样的方式核对。
- **检查更新**，只在你允许之后。Orra 第二次启动时会问你是否自动检查，也可以在“设置 → 关于”里更改。检查时，Orra 大约每天读取一次 https://github.com/db-ol/Orra/releases/latest/download/appcast.xml。每次更新都要你同意后才会安装，而且只安装用本项目更新密钥签名的更新和更新清单。

模型都在你的 Mac 上运行，本身从不联网。在你允许检查更新之前，启动 Orra 从不联网。和所有下载一样，这些服务能看到你的 IP 地址。检查更新时还会看到 Orra 的版本号，以及和所有网页请求一样带上的偏好语言。Orra 不发送账号、令牌或 Cookie，也不发送任何其他关于你的 Mac 的信息。服务器和核对方式的详情见 [docs/model-download.md](model-download.md)（英文）。

**报告问题**会在你的 Mac 上生成一个文本文件，包括 Orra 的版本、设置和权限状态，Mac 的型号、芯片、内存、macOS 版本和语言，麦克风名称，Orra 最近一小时的日志，以及最近 7 天的崩溃报告。它不包含任何听写的文字、录音、剪贴板、个人词库或学到的词。关于“项目”，它只写明“项目”是否打开，以及其中项目、邮件和文件的数量。你的个人文件夹路径、账户名、全名和电脑名都会被去掉。Orra 自己不发送任何东西，它只是在浏览器里打开 GitHub 页面，只有你自己附上，这个文件才会到 GitHub。

要删除模型，请先退出 Orra，再删除上面的 Models 文件夹。如果只想删除整理模型，请先关闭整理和翻译，再删除其中的 Qwen3.5-4B-4bit-0e7ffd5c 文件夹。如果 ~/Library/Caches/qwen3-speech 里有其他 App 留下的副本，也请一并删除，否则 Orra 会从那里重新安装模型。
