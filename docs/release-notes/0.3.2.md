More ways to press the talk and translation keys.

- Each key now has a mode under Keys in Settings: Hold, as before, Press to start and stop, or Double press. Hold stays the default, so nothing changes until you pick another mode.
- Either key can also be a combination, such as Control and Option held together, or Shift Command D. The D of a combination never reaches the app in front, and D alone types as usual.
- Shortcuts that macOS or most apps use, such as Command C, Command V, Command Tab and Control Space, can't be chosen, so copy, paste and switching input sources keep working.
- Your saved keys and Double press for hands free stay as they were.

说话键和翻译键有了更多按法。

- 在设置的“按键”里，每个键都可以选用法：“按住”（和以前一样）、“按一下开始，再按一下结束”或“连按两下”。默认仍是“按住”，不改就一切照旧。
- 两个键都可以设成组合键，比如同时按住 Control 和 Option，或者 Shift Command D。组合键里的 D 不会输入到前台的 app，单按 D 照常打字。
- macOS 或大多数 app 用到的快捷键，比如 Command C、Command V、Command Tab 和 Control Space，不能选作按键，所以复制、粘贴和切换输入法都不受影响。
- 已保存的按键和“连按两下进入免手持模式”都保持不变。
