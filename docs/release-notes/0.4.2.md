Live Captions turn on with one click, and the welcome window stays in the menu after setup.

- Live Captions now sits at the top level of the Orra menu, under the heading Meeting Interpretation, instead of in a submenu. Speak Translations to Others follows it when it shows. It now also shows while it is on after Translation was turned off, so the menu can still turn it off.
- The menu item that opens the welcome window no longer goes away after setup. Once Orra is ready it reads Getting Started… and opens the window with Orra is ready and Try next. Until then it reads Setup Guide…, as before, and so it does for a few seconds after each launch while the speech model loads.
- Stop Speaking while Live Captions run also drops a translation that waits for its turn. Before, the voice model still made that translation later, though nobody heard it, and captions and new dictations waited until it was done. Turning Speak Translations to Others off does the same. Stop Speaking while the voice model loads now also keeps that translation from playing once the model is ready.
- Live Captions do less work while someone talks for a long time without a pause.

“实时字幕”点一下就能打开，设置完成后，欢迎窗口也还能从菜单里打开。

- “实时字幕”从子菜单移到了 Orra 菜单的第一层，放在“会议同传”标题下。“为对方朗读译文”出现时紧跟在它后面。关掉“翻译”后，如果“为对方朗读译文”还开着，菜单里也会显示它，方便直接关掉。
- 设置完成后，菜单里打开欢迎窗口的那一项不会再消失。Orra 准备就绪后它叫“入门指南…”，打开的窗口里有“Orra 已准备就绪”和“还可以试试”。准备就绪之前它仍叫“设置向导…”，每次启动后语音模型载入的那几秒里也是这样。
- 开着实时字幕时点按“停止朗读”，排队等着朗读的译文也会一起丢掉。以前语音合成模型之后仍会把这段译文生成出来，虽然没人听到，字幕和新的听写却都要等它做完。关掉“为对方朗读译文”时也一样。语音合成模型还在载入时点按“停止朗读”，模型载入后也不会再读这段译文。
- 有人长时间不停顿地说话时，实时字幕的计算量更小。
