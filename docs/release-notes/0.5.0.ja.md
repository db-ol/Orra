Orraが日本語とスペイン語に対応し、この2つの言語での音声入力と翻訳がベータ版として加わり、1回の音声入力が最長5分になりました。

- Orraのメニューとウインドウが日本語とスペイン語にも対応しました。OrraはMacの言語に従って表示されます。別の言語にするには、“設定”＞“一般”の“表示言語”で選びます。スペイン語はラテンアメリカのスペイン語です。README、ユーザガイド、プライバシーのページもこの2つの言語で読めるようになり、アップデートのウインドウにはOrraの表示言語でリリースノートが表示されます。
- “設定”＞“一般”に“音声入力の言語”が加わり、英語のほかに話す言語を選べるようになりました。選択肢は“中文（普通话和粤语）+ English”、“日本語 + English（ベータ版）”、“Español + English（ベータ版）”です。1つの文の中で2つの言語を混ぜて話せます。日本語やスペイン語の文は、音声認識モデルが書いたとおりにペーストされます。これまでは、こうした音声の処理に時間がかかり、中国語や英語に翻訳された文がペーストされることもありました。日本語やスペイン語を選んだ場合、“テキストを整える”と“自分の修正から学習”は、今のところ英語の文にのみ対応しています。日本語やスペイン語は、その言語で音声入力する場合にだけ選んでください。
- 翻訳は英語と音声入力の言語の間で行われます。翻訳キーで、日本語やスペイン語は英語に、英語は音声入力の言語に翻訳されます。“翻訳先”では“自動”、“英語”、音声入力の言語から選べます。“ライブキャプション”も同じように翻訳され、“翻訳を相手に読み上げる”は日本語とスペイン語の訳文も読み上げます。
- 1回の音声入力が最長5分（これまでは1分）になり、最後の15秒間はインジケータがカウントダウンします。1分を超える録音は、話が途切れたところで区切って文字起こしされ、M5 Proでは話した1分あたり約2秒かかり、中国語で用語集を使う場合は最大でその2倍かかります。
- “設定”＞“一般”に“画面上の名前を使用（ベータ版）”が加わりました。初期設定ではオフです。オンにすると、音声入力を開始するたびに、カーソルより前のテキストとウインドウのタイトルから名前を取り出し、その名前だけを音声認識モデルに渡して、画面上の名前が同じ表記で書かれるようにします。テキストそのものがモデルに渡ったり、保存されたりすることはありません。パスワードフィールド、セキュア入力が有効なアプリ、パスワードマネージャの1Password、Bitwarden、KeePassXC、Appleの“パスワード”と“キーチェーンアクセス”は読み取りません。既知のリスクとして、画面上の名前が、話した別の名前と似た発音の場合、Orraが画面上の名前のほうを書いてしまうことがあります。
- 設定に“会議通訳”の専用ページができました。サイドバーの“一般”のすぐ下にあります。“ライブキャプション”と“翻訳を相手に読み上げる”の設定はすべてこのページにあります。“翻訳”は引き続き“一般”にあります。
- 新しいユーザの音声入力キーは、初期設定で“押すたびに開始/停止”になり、ようこそウインドウで“押したまま”や“2回押し”に変更できます。以前に設定した音声入力キーの動作は変わりません。
- 広東語では“呃”は“だます”という意味の動詞でもあります。広東語の音声入力では、ほかの漢字のすぐ隣にある“呃”をフィラーのルールが残すようになりました（“佢呃咗我啲钱”など）。“テキストを整える”がオンの場合は、ローカルモデルによって削除されることがあります。
