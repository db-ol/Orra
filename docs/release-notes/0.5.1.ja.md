ライブキャプションで話された内容だけを表示できるようになり、専用の言語とショートカットが加わり、会議全体をコピーできるようになりました。設定に“音声入力”と“翻訳”のページが加わりました。

- キャプションウインドウの上部か、“設定”＞“会議通訳”の“キャプションの表示”で、“原文”、“訳文”、“両方”から選べます。“原文”は話された内容を翻訳せずに表示するので、ローカルモデルの読み込みやダウンロードは行いません。“訳文”と“両方”はこれまでの2つの表示の新しい名前で、選んでいた表示はそのまま変わりません。
- ライブキャプションの言語は“キャプションの翻訳先”で設定するようになりました。キャプションウインドウの上部と“設定”＞“会議通訳”にあります。選択肢は英語と音声入力の言語で、“翻訳先”を変えてもキャプションは変わりません。選んだ言語の文は話されたとおりに表示され、それ以外の文はすべてその言語に翻訳されます。アップデート後は、“翻訳先”で固定していた言語になり、“自動”だった場合は音声入力の言語になります。そのため、音声入力の言語で行われる会議は、英語に翻訳されずに話されたとおりに表示されるようになります。英語で読んでいて、音声入力の言語が“中文（普通话和粤语）+ English”の場合の中国語の会議も同様です。キャプションウインドウで“英語”を選ぶと、また翻訳されます。
- キャプションウインドウの右上にある“すべてのキャプションをコピー”は、ウインドウでの表示どおりにすべての文をコピーします。矢印をクリックすると、原文だけ、訳文だけ、またはその両方もコピーできます。キャプションはOrraを終了するまでメモリ上に残るようになったので、オフにしたあとも、Orraメニューの“キャプションをコピー”でコピーできます。キャプションをもう一度オンにすると、ウインドウは空の状態で始まり、前回の会議は“前回のキャプションをコピー”に残ります。“最後の音声入力をコピー”と同じく、これらのコピーはこのMacにだけ置かれます。音声入力がペーストのあとでコピーをクリップボードに戻したときも、同様になりました。
- “ライブキャプションのショートカット”で、どのアプリからでもキャプションのオンとオフを切り替えられます。最初はキーボード配列にかかわらずControl Option Command C（⌃ ⌥ ⌘ C）です。“設定”＞“一般”＞“キー”で変更でき、“なし”でオフにできます。音声入力キーか翻訳キーがこの組み合わせか、ControlとOptionのようにこのショートカットの修飾キーだけの組み合わせの場合は、ショートカットは“なし”から始まります。
- 設定の新しい“音声入力”ページには、“音声入力の言語”、“テキストを整える”とそのルール、“音声認識”の“自分の修正から学習”と“画面上の名前を使用（ベータ版）”があります。“翻訳”ページには、“翻訳”のスイッチ、“変更…”ボタンのある“翻訳キー”の行、“翻訳先”があります。キーは引き続き“一般”にあり、“画面上のヒント”、サウンド、“ログイン時に開く”、“DockにOrraを表示”は“一般”の“システム”にあります。“2回押してハンズフリー”は“‘押したまま’のとき、2回押すと録音を継続”という名前になって“キー”に移り、動作が“押したまま”のキーがあるときだけ表示されます。“音声入力キー”メニューにはなくなりました。設定の値はすべてそのまま引き継がれます。
- 翻訳を一度もオンにしたことがない場合、翻訳キーは“押すたびに開始/停止”から始まるようになりました。キーを単独で軽く押しただけでも録音が始まるので、意図せず始まった場合は、もう一度押すかEscキーで終了してください。Optionキーのショートカットはそのまま使えます。以前に翻訳をオンにしたことがある場合は、それまでの動作のままです。
- Orraの準備ができていれば、Orraを開くと設定が表示されるようになりました。“ログイン時に開く”がオンの場合は表示されません。
- 新しくインストールした場合、音声入力の言語は自分の言語から始まります。たとえば、1番目が英語で2番目が日本語のMacでは“日本語 + English（ベータ版）”から始まります。セットアップ中は、音声入力の言語を選ぶまで、ようこそウインドウで選んだOrraの言語に合わせて変わります。すでに設定されている音声入力の言語は変わりません。
- 整文や翻訳が制限時間を超えた場合、Orraはモデルが止まるのを待たずに、整文や翻訳をしていないテキストをすぐにペーストするようになりました。これまでは、さらに数秒待つことがありました。
- “自分の修正から学習”は、設定など、Orra自身のウインドウを読み取らなくなりました。
