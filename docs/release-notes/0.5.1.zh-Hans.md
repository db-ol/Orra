实时字幕现在可以只显示原话，有了自己的语言和快捷键，还会保留整场会议供你拷贝。设置里新增了“听写”和“翻译”页面。

- 在字幕窗口顶部，或设置的“会议同传”里的“字幕显示”，可以选“原文”“译文”或“双语”。“原文”只显示说的原话，不翻译，所以不会加载或下载本地模型。“译文”和“双语”就是以前的两种显示方式，只是改了名字，你原来的选择保持不变。
- “实时字幕”有了自己的语言“字幕翻译成”，在字幕窗口顶部和设置的“会议同传”里。可选英文和你的听写语言，“翻译成”不再影响字幕。已经是这种语言的句子按原话显示，其他句子都翻译成这种语言。两种语言都不是的句子翻译成英文，比如听写语言是中文时的日语。更新后，它是你在“翻译成”里固定的语言，选的是“自动”时则是你的听写语言。所以原来选“自动”的话，用听写语言开的会现在按原话显示，不再翻译成英文。你看英文、听写语言却是“中文（普通话和粤语）+ English”时，中文会议也是这样。在字幕窗口里选“英文”，就会重新翻译。
- 字幕窗口右上角的“拷贝全部字幕”会按窗口的显示方式拷贝每一句，点按它的箭头还可以只拷贝原文、只拷贝译文或两者都拷贝。字幕现在会一直保存在内存里，直到你退出 Orra，所以关闭字幕后仍然可以用 Orra 菜单里的“拷贝字幕”拷贝。再次打开字幕时，窗口从空白开始，上一次会议保留在“拷贝上一次的字幕”里。和“拷贝上次听写”一样，这些拷贝只留在这台 Mac 上，现在听写粘贴后把它们放回剪贴板时也是如此。
- “实时字幕快捷键”在任何 App 中都能打开或关闭字幕，不论哪种键盘布局，默认都是 Control Option Command C（⌃ ⌥ ⌘ C）。可以在设置的“通用”里的“按键”中更改，点“无”可以关闭。如果你的说话键或翻译键正好是这个组合，或者是只由它的修饰键组成的组合，比如 Control 和 Option，快捷键就默认为“无”。
- 设置里新的“听写”页面有“听写语言”“整理文字”及其规则，以及“识别”下的“从我的修改中学习”和“使用屏幕上的名字（测试版）”。“翻译”页面有“翻译”开关、带“更改…”的“翻译键”一行和“翻译成”。按键仍在“通用”里，“屏幕提示”、提示音、“登录时打开”和“在程序坞中显示 Orra”在“通用”的“系统”里。“连按两下进入免手持模式”改名为“‘按住’用法下，连按两下可松手继续录音”，放在“按键”里，只在某个键的用法是“按住”时显示，“说话键”菜单里不再有它。移动过的设置都保持原来的值。
- 如果你从没打开过“翻译”，翻译键现在默认是“按一下开始，再按一下结束”。单独轻按一下翻译键也会开始录音，误按时再按一下或按 Esc 键结束。Option 快捷键照常可用。如果你以前打开过“翻译”，翻译键保持原来的用法。
- Orra 准备就绪后，打开 Orra 会显示设置窗口，除非打开了“登录时打开”。
- 新安装的 Orra 默认用你自己的语言作为听写语言，比如英文排第一、日语排第二的 Mac 默认是“日本語 + English（测试版）”。设置过程中，在你选择听写语言之前，它会跟着你在欢迎窗口里为 Orra 选的语言变化。你已有的听写语言保持不变。
- 整理或翻译超过时限时，Orra 现在会立即粘贴没有整理或翻译的文字，不再等模型停下来，以前这可能要多等几秒。
- “从我的修改中学习”不再读取 Orra 自己的窗口，比如设置窗口。
