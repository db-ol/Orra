“プロジェクト”がプレビュー版として加わりました。選んだ“メール”のメールボックスのメールをプロジェクトごとに振り分け、各メールをそのプロジェクトのファイルと合わせて説明し、返信の下書きを作成します。処理はすべて、ローカルモデルを使ってお使いのMac上で行われます。初期設定ではオフで、“設定”＞“プロジェクト”でオンにできます。今後変わることがあります。“ライブキャプション”では、何を聞き取るのか、いつ一時停止するのかが表示されるようになりました。

- プロジェクトをフォルダや関係者と一緒に追加すると、新しいメールがそれぞれのプロジェクトに振り分けられます。どのプロジェクトにも当てはまらないメールは“プロジェクト未定”に入ります。ニュースレターなど、メーリングリストに送られたメールや機械から送られたメールは、プロジェクトの関係者が含まれていなければ“対象外”に入ります。“プロジェクトの候補”は、“プロジェクト未定”のメールからプロジェクトを提案します。候補をクリックすると、内容が入力された状態で“新規プロジェクト”が開きます。
- “説明する”をクリックすると、ローカルモデルがメールの要点を、プロジェクトのファイル、メールの添付ファイル、以前のメールといった出典とともに示し、あなたにしか決められない質問も挙げます。説明は、Orraの表示言語が中国語の場合は中国語で、それ以外の言語の場合は英語で表示されます。日本語とスペイン語の場合も英語です。
- 返信が必要なメールには、メールの言語（中国語または英語）で下書きが作成されます。ほかの言語（日本語など）と判断されたメールには、下書きは作成されません。下書きは直接編集できるほか、下書きの下のボックスに変更内容を入力して“下書きを変更”をクリックすることもできます。カーソルがそのボックスにあるときは音声入力キーで話すこともでき、話し終えると下書きが変更されます。“‘メール’で返信を開く”をクリックすると、“メール”の返信ウインドウが開き、下書きがクリップボードに入ります。返信ウインドウで⌘Vを押し、内容を確認してから自分で送信してください。
- “プロジェクト”は、“メール”アプリを通じて、“メール”が開いている間だけメールを読み取り、ローカルモデルだけで処理します。メールを送信、移動、削除することはなく、メールサーバに接続することもありません。“プロジェクト”での割り当て、編集、削除で変わるのは、このMacに保存された“プロジェクト”のデータだけです。“メール”内のメールは変わりません。保存した内容はこのMacから出ません。“プロジェクト”をオフにするときは、データを残すか削除するかを選べます。読み取るものと保存するものは、“設定”＞“プロジェクト”の“プライバシーの詳細”で確認できます。
- “プロジェクト”を使うには、メモリが16 GB以上のMac、“メール”アプリ、整文モデル（“テキストを整える”のローカルモデル）が必要です。このMacに整文モデルがない場合は、ダウンロード（3.05 GB）するかどうかをOrraが確認します。macOSに確認されたら、Orraによる“メール”の制御を許可してください。次に、メールボックスを選んで“メールの読み取りを開始”をクリックします。それまではメールを読み取りません。“メールの読み取りを開始”をクリックすると“プロジェクト”ウインドウが開き、あとからはOrraメニューからも開けます。
- “プロジェクト”ウインドウを開くと、“‘プロジェクト’の使い方”が表示されます。メールボックスを選ぶところから、“メール”で返信を自分で送信するところまでの手順です。“説明する”をクリックすると、説明と下書きが先に表示され、メールそのものはその下の“元のメール”に表示されます。“説明を非表示”をクリックするとメールが先に表示され、下書きはその下になります。“説明を表示”をクリックすると、説明がまた表示されます。
- 音声入力が優先されます。音声入力中や“ライブキャプション”の実行中は、“プロジェクト”はモデルを使う処理を一時停止します。モデルがメールを振り分けるのは、“プロジェクト”ウインドウが開いている間だけです。ウインドウを閉じている間は、新しいメールはルールだけで振り分けられ、残りはウインドウをもう一度開いたときにモデルが振り分けます。
- “ライブキャプション”をオンにしてまだキャプションがないときは、Macで再生中の音声（通話や動画など）のキャプションが表示され、マイクに向かって話した内容は表示されないことが、キャプションウインドウで案内されるようになりました。音声入力中は、キャプションを一時停止し、終わるとまとめて表示することも案内されます。“Macからの音声がまだ届いていません”というメッセージは、“画面収録とシステムオーディオ録音”でOrraを許可するよう促すもので、何も再生していないときなど、オーディオがまったく届かない場合にも表示されるようになりました。
