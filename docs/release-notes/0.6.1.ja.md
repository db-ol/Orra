プレビュー版の“プロジェクト”が使い始めやすくなり、より多くのファイルを読み取れるようになりました。中国語と英語をまたいで検索できるようになったほか、説明に使うファイルを自分で選んだり、“元のメールと比較”でメールを説明と並べて表示したりできます。メールで求められたファイルを返信に添付することもできます。

- “設定”＞“プロジェクト”で“プロジェクト”をオンにすると、スイッチの下の“‘プロジェクト’を使い始める”に、整文モデルのダウンロードから最初のプロジェクトの作成までの手順が並び、終わった手順にはチェックマークが付きます。手順や“プロジェクト”ウインドウで“メール”が必要なときは、“‘メール’を開く”で“メール”アプリを開けます。“プロジェクト”がオフのときは、Orraメニューに“‘プロジェクト’を設定…”が表示されます。
- “プロジェクト”は、プロジェクトのフォルダと添付ファイルにあるExcelとPowerPointのファイルを読み取れるようになり、図面やビデオなど、プロジェクトのフォルダにあるそのほかのファイルも名前で把握します。また、画像とスキャンしたPDFのページのテキストを、macOSのテキスト認識で読み取ります。認識はほかのファイルのあとに、音声入力をしていない間に行います。読み取れるのは中国語と英語で、そのほかの言語の文字はアクセント記号なしで読み取り、日本語は一部しか読み取れません。プロジェクトのページには、認識を待っている画像とスキャンの数が表示されます。画像から認識した抜粋には、語句や数字が誤っている可能性があることが表示されます。
- “説明する”をクリックすると、整文モデルがまずメールを中国語と英語の検索語にし、同じものを指すほかの言い方も加えます。これで、中国語のメールが英語のファイルを、英語のメールが中国語のファイルを見つけやすくなります。
- “プロジェクト未定”のメールや、検索語がそのメールのプロジェクトのファイルよりもほかのプロジェクトのファイルによく合うメールには、ほかのプロジェクトのフォルダの箇所が、そのプロジェクトの名前付きで加わることがあります。モデルはそれらの箇所を含まない別のリクエストで下書きを書くため、少し時間がかかります。要点の下にもそのことが表示されます。“プロジェクトを削除…”では、そのプロジェクトのファイルを使ったほかのメールの説明と下書きも削除されるようになりました。
- “メールの要点”の下の“この説明のプロジェクトのファイル”には、モデルに渡したプロジェクトのファイルが、フォルダ、要点で引用されているかどうか、“検索で見つかった”などの含めた理由とともに表示されます。各チップにはページ、スライド、シートが示され、クリックすると保存された抜粋が表示されます。
- この一覧の下かメールのコンテキストメニューにある“このメールのファイルを選択…”では、どのプロジェクトのファイルでも6つまでチェックを入れられます。最初に説明する前でも使えます。次の説明では、それらのファイルのうち最も合う箇所が先に入り、残りはOrraの検索で埋められます。下書きに使われることもあります。プロジェクトのフォルダの外にあるファイルは読み取りません。そうしたファイルをファイルの一覧にドラッグしても、Orraはそのフォルダをプロジェクトに追加するよう提案するだけです。
- 書類を送るようメールで求められたときは、“求められているファイル”にその依頼が引用され、該当しそうなファイルが、メールのプロジェクトのものから順に表示されます。“返信に添付”にチェックを入れるか、“返信の添付ファイル”の“ファイルを追加…”で追加すると、“‘メール’で返信を開く”または“全員に返信”をクリックしたときに、それらのファイルが“メール”の返信ウインドウに添付されます。自分でチェックを入れるまで、どのファイルにもチェックは入りません。差出人がなりすましの可能性がある場合、ファイルは提示されません。
- “もう一度説明する”の横の“元のメールと比較”をクリックすると、メールが説明と下書きと並んで表示され、それぞれ別々にスクロールできます。サイドバーは隠れ、メールのリストはそのまま残ります。“比較を終了”をクリックすると、サイドバーが元に戻ります。
- メールそのものを[E1]として引用した要点には、[E1]と“情報源の記載なし”ではなく、“このメール”のチップが表示されるようになりました。[F1]のような情報源のIDは質問と下書きに表示されなくなり、返信に入って“メール”に渡ることもなくなりました。
- “プロジェクト”が読み取るのは、これまでどおり、選んだメールボックスと、追加したフォルダ内のファイルだけです。テキスト認識と新しい検索は、macOSとすでにある整文モデルを使ってこのMac上で行われ、新たにダウンロードするものはありません。Orraが“メール”アプリを開くのは、“‘メール’を開く”をクリックしたときだけです。
- Orraが添付するのはチェックを入れたファイルだけで、それも“‘メール’で返信を開く”または“全員に返信”をクリックしたときに限ります。送信する前に、“メール”がその返信を添付ファイルごとメールサーバ上のアカウントの“下書き”に保存することがあります。Orraによる“メール”の制御を許可するかどうかをmacOSがもう一度尋ねた場合、その確認には、返信を開いてチェックを入れたファイルを添付するのはクリックしたときだけであることも書かれるようになりました。
- 0.6.1が“プロジェクト”のデータを開いたあとは、以前のバージョンのOrraではそのデータを開けません。以前のバージョンでは、“設定”＞“プロジェクト”で“‘プロジェクト’のすべてのデータを削除…”を選ぶまで、データを開けないことが表示されます。
