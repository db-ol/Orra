“项目”仍是预览版，现在更容易上手，也能读取更多文件。它能跨中英文搜索，让你选择解释要用的文件，还能用“对照邮件原文”对照显示邮件和它的解释。

- 在设置的“项目”里打开“项目”后，开关下面的“开始使用‘项目’”会列出从下载整理模型到创建第一个项目的各个步骤，每完成一步就打上勾。在需要“邮件”的步骤和“项目”窗口里，点按“打开‘邮件’”就能打开“邮件” App。“项目”关闭时，Orra 菜单里会显示“设置‘项目’…”。
- “项目”现在会读取项目文件夹中和邮件附件里的 Excel 和 PowerPoint 文件，以及项目文件夹中的 CSV 文件。它也会按文件名记下项目文件夹中的其他所有文件，比如图纸或视频。它还会用 macOS 的文字识别读取项目文件夹中的图片和扫描的 PDF 页面里的文字，在读完其他文件之后进行，你听写时会暂停。文字识别能读取中文和英文，其他语言的拉丁字母会读成不带重音符号的字母，日文只能读出一部分。项目的页面会显示还有多少图片和扫描件等待识别，从图片中识别出的摘录会注明其中的文字和数字可能有误。
- 点按“解释”后，整理模型会先把邮件变成中英文的检索词，并加上同一事物的其他说法，所以中文邮件更容易找到英文文件，英文邮件也更容易找到中文文件。
- “待归入项目”里的邮件，以及检索词与其他项目的文件比与自己项目的文件更相符的邮件，也可能用到你其他项目文件夹中的段落，并注明出自哪个项目。模型会另发一次不含这些段落的请求来写草稿，所以要多花一点时间，要点下面也会有一行说明。“移除项目…”现在还会删除用到这个项目的文件的其他邮件的解释和草稿。
- “邮件要点”下面的“本次解释的项目文件”会列出模型拿到的项目文件，注明所在的文件夹、有没有要点引用它，以及加入的原因，比如“通过搜索找到”。点按标签可以查看保存的摘录，标签会写明页、幻灯片或工作表。
- 在这个列表下面或邮件的快捷菜单里选择“为这封邮件选择文件…”，可以从任何项目中勾选最多 6 个文件，第一次解释之前也可以。下一次解释会先放入这些文件中最相关的段落，再用自己的搜索补足其余段落，草稿也可能用到它们。Orra 从不读取项目文件夹以外的文件。把这样的文件拖到可以勾选的文件列表上，Orra 只会提出把它所在的文件夹添加到项目。
- “重新解释”旁边的“对照邮件原文”会把邮件和它的解释、草稿对照显示，各自滚动。边栏会隐藏，邮件列表保留，点按“退出对照”边栏就会回来。
- 以 [E1] 引用邮件本身的要点，现在会显示“本邮件”标签，不再显示 [E1] 和“未提供来源”。[F1] 这类来源编号也不再出现在问题和草稿里，所以不会再随回复进入“邮件”。邮件列表上方或下方有一行较长的文字时，“项目”窗口的顶部和底部不会再被截掉。
- “项目”仍然只读取你选择的邮箱，以及你添加的文件夹中的文件。文字识别和新的搜索都在这台 Mac 上进行，用的是 macOS 和你已有的整理模型，不需要下载任何新东西。只有你点按“打开‘邮件’”时，Orra 才会打开“邮件” App。
- 0.6.1 打开“项目”的数据后，更早版本的 Orra 就无法再打开这些数据，在你点按设置的“项目”里的“删除‘项目’的所有数据…”之前，会一直提示无法打开。
