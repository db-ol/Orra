このアップデートでは、“プロジェクト”がより慎重にメールを振り分け、“メール”の応答が遅いときも読み取りを続けるようになりました。ライブキャプションは、Macで何も再生されていないときにそのことを表示します。

- “プロジェクト”は、プロジェクトの人、プロジェクトの語句、プロジェクトにリンクしたメールボックスなど、そのプロジェクトを指す手がかりがあるときにだけ、メールをそのプロジェクトに振り分けるようになりました。手がかりのないメールは、プロジェクトが1つだけの場合も“プロジェクト未定”に残ります。以前のバージョンが整文モデルの選択だけで振り分けたメールは、一緒に振り分けられた返信とともに、一度だけ振り分け直されます。自分で移動したメールと、下書きのあるメールはそのまま残ります。
- “要返信”は、あなたに質問や依頼をしているメールにだけ付くようになりました。あなたがCCにだけ含まれるメール、グループのアドレス宛てのメール、BCCで届いたメールには、あなたの名前が書かれていない限り付きません。依頼の書かれていない転送のお知らせや、it-noreply@のようなアドレスからの自動メールにも付きません。
- “メール”が一部のアカウント、メールボックス、メールに対して応答が遅いとき、“プロジェクト”は最初からやり直さずに残りを読み進め、遅い部分は後でもう一度読み取ります。新しいメールは10通ごとに表示されるので、早く表示されます。組織のネットワークの外で接続が切れる職場や学校のExchangeアカウントで特に効果があります。
- ライブキャプションは、Macで何も再生されていないときにそのことを表示し、キャプションに表示されるのは通話や動画などMacで再生中の音声で、マイクに向かって話した内容ではないことを説明するようになりました。何かが再生されているのにOrraに音声が届かないときは、これまでどおり権限の確認を勧めます。
