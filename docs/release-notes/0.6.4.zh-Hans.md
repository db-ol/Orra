这次更新让实时字幕可以显示你对着麦克风说的话，字幕可见时屏幕会保持亮着，还修正了从修改中学习和翻译回复时的两个问题。

- 想为你说的话显示字幕，请在字幕窗口左上角的菜单中，或设置的“会议同传”里的“字幕来源”，选择“麦克风”。每次启动 Orra 都从“Mac 播放的声音”开始，所以只有在你选择之后，字幕才会使用麦克风。字幕使用的麦克风和听写相同，窗口会显示“麦克风已打开”和它的名称。
- 你关闭字幕、关闭字幕窗口或选择“Mac 播放的声音”时，字幕会立即释放麦克风。锁定屏幕时，以及其他用户在使用这台 Mac 时，字幕也会释放麦克风，等你解锁或回来后再重新打开。听写时字幕会暂停，所以你听写的内容不会变成字幕。
- 实时字幕在收听而且窗口可见时，无论字幕来源是哪一种，屏幕都不再自动变暗或关闭。关闭字幕或窗口后、窗口看不见时、屏幕锁定后，以及大约 5 分钟没有声音时（比如通话结束后），屏幕会照常变暗和关闭。你仍然可以随时锁定屏幕或合上盖子。
- 打开“从我的修改中学习”后，以前如果你把一个词改成含有中文数字的词（比如把“开会”改成“十点”），或改成单个字母（比如把 plan A 改成 plan B），即使两者发音不同，Orra 也可能把它当成听错的词学进个人词库。现在，这样的修改和其他修改一样，只在发音相近时才会学习。把一个字改成发音不同的数字（比如把“两点”改成“三点”）时，也不会再询问是否把词加入个人词库。
- 翻译键现在会翻译以“可以”“行”“不好意思”或“嘿”这类词开头的回复，日语和西班牙语里类似的回复也一样。它们的译文以 Sure、OK、Sorry 或 Hey 开头，以前会被防止模型答话而不翻译的检查拦下，所以 Orra 粘贴的是没有翻译的原文。
