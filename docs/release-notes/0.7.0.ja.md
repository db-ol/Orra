このアップデートでは、話した内容を明快または簡潔な書き言葉に書き直す推敲と、オーディオファイルやビデオファイルをテキストにするファイルの文字起こしが加わりました。どちらもお使いのMac上で行われます。

- “設定”＞“音声入力”の“ローカルモデルで整文”のすぐ下に、“ローカルモデルで推敲”が加わりました。初期設定ではオフです。ベータユーザからの要望に応えた機能です。“スタイル”では、話した内容をほぼすべて残す“明快”（デフォルト）か、要点だけを残す“簡潔”を選べます。“簡潔”は通常、話した長さの半分ほどになります。推敲は“テキストを整える”のモデルを使うため、整文がオフでも使えます。このMacにまだモデルがない場合は、ダウンロードする前にOrraが確認します。
- 推敲がオンの間は、音声入力キーで入力した内容をOrraが推敲します。整文もオンの場合は、整文の代わりに推敲します。フィラー、“中中英”のような繰り返し、言いかけてやめた部分を取り除き、文法と句読点を直します。意味、名前、数字、混ぜて話した言語はそのまま残り、何も翻訳しません。質問は質問のままで、モデルが話した内容に答えたり実行したりすることはありません。整文と同じように、音声入力の処理に少し時間がかかります。
- 音声入力が長すぎて推敲できない場合や、推敲の結果がOrraのチェックに通らない場合、時間がかかりすぎた場合は、推敲しないときと同じテキストがペーストされるため、話した内容が失われることはありません。Orraメニューの“原文をペースト”で話したとおりのテキストを戻せます。推敲してペーストしたテキストから、Orraが修正を学習することはありません。翻訳キーで入力した内容、ライブキャプション、ファイルの文字起こし、“プロジェクト”は推敲の対象になりません。音声入力の言語が日本語かスペイン語の場合、推敲は整文と同じく、今のところ英語の文にのみ対応しています。
- Orraメニューの“ファイルを文字起こし…”で、ボイスメモ、通話の録音、ビデオなどのオーディオファイルかビデオファイルを、1つずつテキストにできます。形式は、M4A、MP3、WAV、MP4、MOVなど、macOSで再生できるものです。ファイルをウインドウにドラッグするか、“ファイルを選択…”をクリックして選ぶと、Orraが音声入力と同じ音声認識モデル、音声入力の言語、用語集を使って、お使いのMac上で文字起こしします。フィラーと数字のルールは設定のスイッチどおりに適用しますが、整文と推敲は行いません。ウインドウには、各文がその開始時間とともに順に表示され、残り時間も表示されます。“停止”をクリックしても、それまでの結果は残ります。
- “コピー”は時間を除いたテキストをコピーし、“テキストとして保存…”はテキストファイルを、“字幕として保存…”は時間の付いた字幕の.srtファイルを保存します。.srtファイルはビデオプレーヤーや編集アプリで読み込めます。保存していないテキストが、別のファイルを選ぶ操作やウインドウを閉じる操作で失われる場合は、Orraが先に確認します。ファイルの翻訳にはまだ対応していません。
- 音声入力が優先されます。音声入力キーか翻訳キーを押すと、次の文より先に音声入力が音声認識モデルを使い、ペーストのあとでファイルの文字起こしが続きます。ライブキャプションがオンの間はファイルは待機し、オフにすると続きます。Orraが読み込むのは選んだファイルだけで、オーディオをディスクに書き込むことはなく、テキストはウインドウを閉じるか別のファイルを選ぶまでメモリ上にだけ保持されます。iCloud Driveにあって、まだこのMacにダウンロードされていないファイルには手を付けないため、Macにダウンロードさせることはありません。
