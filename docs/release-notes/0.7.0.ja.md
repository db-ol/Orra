このアップデートでは、話した内容を明快または簡潔な書き言葉に書き直す推敲と、オーディオファイルやビデオファイルをテキストにするファイルの文字起こしが加わりました。どちらもお使いのMac上で行われます。

- “設定”＞“音声入力”の“ローカルモデルで整文”のすぐ下に、“ローカルモデルで推敲”が加わりました。初期設定ではオフです。ベータユーザからの要望に応えた機能です。“スタイル”では、話した内容をほぼすべて残す“明快”（デフォルト）か、要点だけを残す“簡潔”を選べます。“簡潔”は通常、話した長さの半分ほどになります。推敲は“テキストを整える”のモデルを使うため、整文がオフでも使えます。このMacにまだモデルがない場合は、ダウンロードする前にOrraが確認します。
- 推敲がオンの間は、音声入力キーで入力した内容をOrraが推敲します。整文もオンの場合は、整文の代わりに推敲します。フィラー、“中中英”のような繰り返し、言いかけてやめた部分を取り除き、文法と句読点を直します。意味、名前、数字、混ぜて話した言語はそのまま残ります。翻訳はせず、話した内容に答えたり実行したりすることもありません。整文と同じように、音声入力の処理に少し時間がかかります。
- 音声入力が長すぎて推敲できない場合や、推敲の結果がOrraのチェックに通らない場合、時間がかかりすぎた場合は、推敲しないときと同じテキストがペーストされます。Orraメニューの“原文をペースト”で話したとおりのテキストを戻せます。推敲してペーストしたテキストから、Orraが修正を学習することはありません。翻訳キー、ライブキャプション、“プロジェクト”はこれまでどおりです。音声入力の言語が日本語かスペイン語の場合、推敲は整文と同じく、今のところ英語の文にのみ対応しています。
- Orraメニューの“ファイルを文字起こし…”で、ボイスメモ、通話の録音、ビデオなど、macOSで再生できるオーディオファイルかビデオファイルを、1つずつテキストにできます。ファイルをウインドウにドラッグするか、“ファイルを選択…”をクリックして選ぶと、Orraが音声入力と同じ音声認識モデル、音声入力の言語、用語集を使って、お使いのMac上で文字起こしします。整文と推敲は行いません。ウインドウには、各文がその開始時間とともに順に表示され、残り時間も表示されます。“停止”をクリックしても、それまでの結果は残ります。
- “コピー”は時間を除いたテキストをコピーし、“テキストとして保存…”はテキストファイルを、“字幕として保存…”は時間の付いた字幕の.srtファイルを保存します。.srtファイルはビデオプレーヤーで読み込めます。保存していないテキストが、別のファイルを選ぶ操作やウインドウを閉じる操作で失われる場合は、Orraが先に確認します。ファイルの翻訳にはまだ対応していません。
- 音声入力が優先され、ペーストのあとでファイルの文字起こしが続きます。ライブキャプションがオンの間は、ファイルは待機します。Orraが読み込むのは選んだファイルだけで、テキストはウインドウを閉じるか別のファイルを選ぶまでメモリ上にだけ保持されます。iCloud Driveにあって、まだこのMacにダウンロードされていないファイルには手を付けないため、Macにダウンロードさせることはありません。
