This update adds Polish, which rewrites what you say as clear or concise written text, and Transcribe File, which turns an audio or video file into text, both on your Mac.

- Polish with a local model is new in Settings, Dictation, right under the cleanup switch, and off until you turn it on. Beta users asked for it. Under Style, Clear, the default, keeps nearly everything you said, and Concise keeps only the points, usually about half as long as what you said. Polish uses the model of Clean Up Text, also while cleanup is off, and if this Mac does not have the model yet, Orra asks before it downloads it.
- While Polish is on, Orra polishes your dictations of the talk key, in place of the cleanup when cleanup is on too. It removes fillers, repeats such as 中中英 and false starts, and fixes grammar and punctuation. It keeps your meaning, names, numbers and the languages you mix, and translates nothing. A question stays a question, and the model never answers or carries out what you say. Like cleanup, it adds some time to a dictation.
- When a dictation is too long to polish, or a polish fails Orra's checks or takes too long, Orra pastes what it would paste without Polish, so nothing you say is lost. Paste Original Text in Orra's menu brings back what you said, and Orra never learns corrections from a polished paste. Polish leaves the translation key, Live Captions, Transcribe File and Projects as they are. With Japanese or Spanish as the dictation language, Polish works on English sentences only for now, as cleanup does.
- Transcribe File… in Orra's menu turns one audio or video file into text, such as a voice memo, a recorded call or a video in M4A, MP3, WAV, MP4, MOV or another format macOS plays. Drop the file on the window or pick it with Choose File…, and Orra transcribes it on your Mac with the speech model, dictation language and vocabulary of your dictations. The filler and number rules apply as your switches say, but not cleanup or Polish. The window shows each sentence with its start time as it comes, and the time left. Stop keeps what is done.
- Copy takes the text without times, Save as Text… saves it as a text file, and Save as Subtitles… saves an .srt file of subtitles with their times, which video players and editors read. Orra asks before another file or closing the window throws away text you have not saved. A file is not translated yet.
- Your dictations go first. A press of the talk key or the translation key gets the speech model before the next sentence, and the file goes on after the paste. While Live Captions are on, the file waits, and it goes on once you turn them off. Orra reads only the file you chose, writes no audio to disk and keeps the text in memory until you close the window or choose another file. A file in iCloud Drive that is not on this Mac yet is left alone, so Orra never makes your Mac download it.
