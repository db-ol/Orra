This update adds Polish, which rewrites what you say as clear or concise written text, and Transcribe File, which turns an audio or video file into text, both on your Mac.

- Polish with a local model is new in Settings, Dictation, right under the cleanup switch, and off until you turn it on. Beta users asked for it. Under Style, Clear, the default, keeps nearly everything you said. Concise keeps only the points, and rambling speech often comes out about half as long. Polish uses the model of Clean Up Text, also while cleanup is off, and if this Mac does not have the model yet, Orra asks before it downloads it.
- While Polish is on, Orra polishes your dictations of the talk key, in place of the cleanup when cleanup is on too. It removes fillers, repeats such as 中中英 and false starts, and fixes grammar and punctuation. A rewrite can leave out a detail or change what you meant, most often in Concise. Like cleanup, Polish adds some time to a dictation.
- When a dictation is too long to polish, or a polish fails Orra's checks or takes too long, Orra pastes what it would paste without Polish. The checks catch some changes of meaning, not all of them. Paste Original Text in Orra's menu brings back the text from before the rewrite, and Orra never learns corrections from a polished paste. The translation key, Live Captions and Projects work as before. With Japanese or Spanish as the dictation language, Polish works on English sentences only for now, as cleanup does.
- Transcribe File… in Orra's menu turns an audio or video file into text, such as a voice memo, a recorded call or a video in M4A, MP3, WAV, MP4, MOV or another format macOS plays. Drop it on the window or pick it with Choose File…, and Orra transcribes it on your Mac with the speech model, dictation language and vocabulary of your dictations. The filler and number rules apply as your switches say, but not cleanup or Polish. The window shows each sentence with its start time as it comes, and the time left. Stop keeps what is done.
- Copy takes the text without times, Save as Text… saves a text file, and Save as Subtitles… an .srt file with the times, which video players read. Orra asks before another file or closing the window throws away text you have not saved. A file is not translated yet.
- Your dictations go first, and the file goes on after the paste. While Live Captions are on, the file waits. Orra reads only the file you chose, writes no audio to disk and keeps the text in memory until you close the window or choose another file. A file in iCloud Drive that is not on this Mac yet is left alone, so Orra never makes your Mac download it.
