这次更新新增了润色和转写文件。润色把你说的话改写成通顺或简洁的书面文字，转写文件把音频或视频文件转成文字，两者都在你的 Mac 上完成。

- 设置的“听写”里，“用本地模型整理文字”下面新增了“用本地模型润色文字”，默认关闭。这是测试用户提出的需求。在“润色风格”里，“通顺”（默认）基本保留你说的所有内容，“简洁”只留要点，通常缩短到一半左右。润色使用“整理文字”的模型，即使整理关闭也能用。这台 Mac 上还没有这个模型时，Orra 会先询问再下载。
- 打开润色后，Orra 会润色你用说话键听写的内容，整理也打开时用润色代替整理。它会去掉语气词、“中中英”这样的重复和说到一半重来的话，改好语法和标点，并保留你的意思、名字、数字和夹杂使用的语言，什么都不会翻译。问题还是问题，模型不会回答或执行你说的内容。和整理一样，润色会让听写多花一些时间。
- 听写太长无法润色，或者润色结果没通过 Orra 的检查、用时太长时，Orra 会粘贴不润色时会粘贴的文字，所以你说的话不会丢。Orra 菜单中的“粘贴原文”可以找回你说的原话，Orra 也不会从润色后粘贴的文字中学习更正。翻译键、实时字幕、转写文件和“项目”都不受润色影响。听写语言是日语或西班牙语时，润色和整理一样，目前只处理英文句子。
- 在 Orra 菜单中选择“转写文件…”，可以把一个音频或视频文件转成文字，比如语音备忘录、通话录音或视频，格式可以是 M4A、MP3、WAV、MP4、MOV 或其他 macOS 能播放的格式。把文件拖到窗口里，或点按“选取文件…”来选择，Orra 就会在你的 Mac 上用听写时的语音模型、听写语言和个人词库转写它。语气词和数字规则按你的开关处理，但不做整理，也不润色。窗口会随时显示每一句和它的开始时间，以及剩余时间。点按“停止”会保留已转写的部分。
- 点按“拷贝”会拷贝不带时间的文字，“保存为文本…”保存为文本文件，“保存为字幕…”保存带时间的 .srt 字幕文件，视频播放器和剪辑软件都能读取。选择另一个文件或关闭窗口会丢掉还没保存的文字时，Orra 会先询问。转写文件暂时不能翻译。
- 你的听写优先。按下说话键或翻译键后，语音模型先处理听写，再转写下一句，粘贴之后文件接着转写。实时字幕打开时，文件会等待，关闭实时字幕后继续。Orra 只读取你选择的那一个文件，不把任何音频写到磁盘上，文字只保存在内存中，直到你关闭窗口或选择另一个文件。在 iCloud 云盘里、还没下载到这台 Mac 上的文件，Orra 不会去读，所以不会让你的 Mac 下载它。
