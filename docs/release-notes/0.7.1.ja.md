このアップデートでは、うっかり2回言った語を整文で1回にするようになり、数だけを変える修正をOrraが学習しなくなり、中国語のテキストで1文字ずつ離して書かれた大文字がつながるようになりました。

- “ローカルモデルで整文”がオンのとき、“我我觉得”や“the the”のように中国語や英語でうっかり2回言った語も、整文で1回にするようになりました。推敲ではすでにそうしています。これまでは、フィラーや言い直しのない音声入力では、こうした繰り返しが残っていました。“看看”、“对对对”、“very very”のように意図した繰り返しは残します。
- 意図して繰り返した語を、モデルが1つ取り除いてしまうことはまだあります（“非常非常”が“非常”になるなど）。また、“中中英”のように単語の中で繰り返した文字は残ることがあります。“看看”のように同じ字を重ねた語も含め、繰り返しのある音声入力もモデルに渡すようになったため、フィラーのある音声入力と同じく、整文の分だけ少し時間がかかります。
- “自分の修正から学習”がオンのとき、Qwen2をQwen3にしたり、十四を四十にしたりするような数だけを変える修正が、誤認識された単語として学習されることがありました。また、四点を十点にすると、用語集に単語を追加するかどうか確認していました。今後は、このような修正を学習することも確認することもなくなり、以前のバージョンがこうして学習したものが音声入力の数字を書き換えることもなくなります。Windows十一をWindows11にするような、同じ数の書き方だけを変える修正は、これまでどおり学習します。
- 中国語のテキストで音声認識モデルが1文字ずつ離して書いた大文字を、Orraがつなげるようになりました。“P R”は“PR”に、“3.5G B”は“3.5GB”に、“O.K.”は“OK”になります。音声入力とファイルの文字起こしの両方で行われ、この処理には個別のスイッチはありません。“Lee 的拼写是 L E E”のようにスペルについて話している音声入力では、文字は離したままです。
