このアップデートでは、話している間にOrraが聞き取った内容を表示できるようになりました。

- “設定”＞“音声入力”の“音声入力の言語”のすぐ下に、“話している間にテキストを表示”が加わりました。初期設定ではオフです。オンにすると、話している間、画面下部の音量バーの上に、Orraが聞き取った内容を表示します。使用中のアプリのフォーカスは奪いません。ペーストはこれまでどおり、音声入力が終わったときに1回だけ行われ、ペーストされるテキストが表示された内容と異なることがあります。表示されたテキストは、ペーストも保存もされず、ログにも記録されません。話している間も音声認識モデルが動作するため、消費電力が増えます。
