# Orra 使用指南

Orra 的概览和下载见 [README](../README.zh-CN.md)，隐私的详细说明见 [privacy.zh-CN.md](privacy.zh-CN.md)。

## 开始使用

1. 打开 Orra，欢迎窗口里有个小向导，会告诉你下一步做什么，带你完成四步。先在窗口顶部选择 Orra 的语言：English、简体中文、日本語、Español，或跟随 Mac 系统，窗口会立即换成这种语言。下面再选择你听写用的语言，见下文的“听写语言”。两者之后都可以在“设置 → 通用”里更改。前三步让 Orra 可以使用，最后一步可以跳过：
   - **下载模型**，只需一次。内存 16 GB 及以上的 Mac 上，点按“下载模型（5.52 GB）”会先下载语音模型（2.47 GB），再下载用来整理你说的话的第二个本地模型（3.05 GB），共用一个进度条，并打开整理功能。语音模型装好后就可以听写。整理模型运行时约占 4 GB 内存，可以在“设置 → 通用”的“整理文字”里关闭整理。内存更小的 Mac 上，这一步只下载语音模型，之后可以在“设置 → 通用”里打开整理功能。
   - **允许使用麦克风。**
   - **允许辅助功能**，Orra 需要它来识别说话键和粘贴文字。系统设置打开后，旁边会出现一张小卡片，用动画演示在哪里打开 Orra。在列表里打开 Orra 后，卡片会自动消失。如果你之前拒绝了麦克风权限，点按麦克风这一步的“打开麦克风设置…”后，系统设置旁边也会出现类似的卡片。
   - **选择说话键**，按一下你想用的键就行。用 Mac 自带的键盘时，左下角的 fn（地球仪）键在右手用鼠标时很顺手。用外接键盘时，右侧 Control 键最合适，因为有些外接键盘（比如 Logitech MX Keys）的 fn 键信号根本传不到 Mac。如果两种键盘换着用，可以在设置里把另一个键加为第二个说话键，见下面的“按键”。在说话键下面选它的用法：新用户默认是“按一下开始，再按一下结束”，也可以选“按住”或“连按两下”。
2. 按一下说话键（默认是右侧 Control 键，可以更换）开始说话，说完再按一下，文字会出现在光标所在的位置。用法选“按住”时，说话时一直按住这个键，松开就结束。选“连按两下”时，快速连按两下开始。麦克风开始传来声音时，Orra 会播放开始提示音，提示音之后说的话都会录下来。说话时，屏幕底部的深色小胶囊里有一排白色音量条随你的声音跳动（可以在设置里关掉），菜单栏里会出现 macOS 的橙色麦克风标志。
3. Orra 在菜单栏和程序坞里，其他功能都在它的菜单和设置里。Orra 准备就绪后，欢迎窗口会显示“还可以试试”：整理、翻译和会议同传，还没打开的功能旁边有一个按钮，可以直接打开设置里它所在的页面。要再次打开欢迎窗口，在 Orra 准备就绪之前选择 Orra 菜单里的“设置向导…”，准备就绪后选择“入门指南…”。

## 使用说明

- **按键。** 说话键和翻译键都在“设置 → 通用 → 按键”里。点按键的输入框（或“更改…”），再按你想用的键：fn（地球仪）键，左侧或右侧的 Control、Option、Command 键，或者组合键，比如同时按住 Control 和 Option，或者 Shift Command D。不同键盘上同一个键的叫法不一样，所以输入框会显示 Mac 上的名称和符号，Option 和 Command 键还会注明 Windows 布局键盘上印的名称，比如“⌥ 右侧 Option 键（Alt）”“⌘ 右侧 Command 键（Windows 键）”。菜单里的“说话键”会显示当前的键，并能打开设置来更改。每个键都可以选用法：“按住”“按一下开始，再按一下结束”或“连按两下”。新用户的说话键默认是“按一下开始，再按一下结束”，翻译键默认是“按住”。用旧版本设置好的说话键仍是“按住”，直到你改选其他用法。用“按住”时，左侧的 Control、Option、Command 键要单独按住片刻才开始录音。用“按一下开始，再按一下结束”时，快速按一下这些键，松开时开始录音。两种情况下，它们的快捷键都照常可用。Shift 键、大写锁定键和会输入文字的键不能单独作为按键，macOS 或大多数 App 用到的快捷键，比如 Command C 或 Control Space，也不能选。输入框会说明原因，以及可以用哪些键。组合键里的普通键不会输入到前台的 App，单按它照常打字。说话键下面的“第二个键”可以再加一个单独的键，用法和说话键完全相同，比如在 fn 键之外加上右侧 Control 键。换用 fn 键传不到 Mac 的外接键盘时，这样很方便。说话键是 fn 键、又没有第二个键时，接上外接键盘后 Orra 会提示添加一次。如果旧版本里同时开了几个说话键，Orra 会保留一个：优先 fn 键，其次右侧 Control 键，然后是其他右侧的键，最后是左侧的键。
- **免手持模式。** 按键用“按住”时，快速连按两下，松开后继续说。屏幕底部的指示条会提示按哪个键结束，按一下就会粘贴，按 Esc 键则取消。每次最多录 5 分钟，见下面的“长听写”。可以在“设置 → 通用 → 听写”里关闭连按两下。
- **长听写。** 不论用哪种方式开始，每次最多录 5 分钟。最后 15 秒，指示条会倒数秒数，停止后会说明原因。超过 1 分钟的录音会在停顿处切成每段不超过 1 分钟，你松开后 Orra 逐段转写。在 M5 Pro 上，每分钟语音大约要等 2 秒，中文加上个人词库时最多再翻一倍。有一段无法转写时，Orra 会粘贴其余部分，并提示你。超过 400 个字符的听写不整理，超过 300 个字符的不翻译，这样直接粘贴时 Orra 也会提示。在免手持模式、“按一下开始，再按一下结束”和“连按两下”里，你想用来结束录音的那一下，可能在上限停止录音之后才按。所以在提示消失之前（提示出现后 30 秒），再按一下那个键只会关掉提示，不会开始新的录音。按键用“按住”时，按住不放照常录音，快速连按两下也照常开始免手持模式。
- **个人词库。** 在“设置 → 个人词库”里添加你常用的词和名字。每次听写，Orra 会把你最近添加或用过的 200 个词提供给语音模型，因为列表越长，每个词的帮助越小，每次听写也越慢。在测试语音上，这些词的正确率中文从约 84% 提高到 99%，英文从 83% 提高到 96%，而且没说到的词几乎不会被凭空加进来。词库最多可以放 5000 个词，这个上限只是为了防止数据失控。表格里显示每个词是你添加的还是 Orra 学到的、Orra 曾把它听成什么，以及你上次用到它的时间。
- **从你的修改中学习。** 在“设置 → 通用 → 听写”里打开“从我的修改中学习”。听写后你马上改正了一个听错的词，Orra 会把你的写法加入个人词库，并弹出提示，你可以撤销。去掉或加上单词之间的空格也算，比如把 read me 改成 readme。如果你只改了名字里的一个汉字，比如把“林悦”改成“霖悦”，Orra 会先询问你，并给出它猜的完整词语，你可以修改后再添加。之后的听写里，如果语音模型还是写成听错的样子，Orra 会换成你的写法，前提是学习开着、这个词还在个人词库里。只由普通词组成的听错写法（比如把 there 改成 their）从不替换。把听错的写法改回去，就不再替换。从个人词库删掉的词，下次再改正时会重新学到，点过“撤销”的词则不会。学习在 macOS 能读取文字的 App 里有效，比如备忘录、邮件和 Safari。在其他 App 里，可以拷贝这个词，再从 Orra 的菜单里添加。
- **使用屏幕上的名字（测试版）。** 默认关闭，在“设置 → 通用 → 听写”里打开“使用屏幕上的名字（测试版）”。每次开始听写时，Orra 会读取你听写的输入框里光标前最多 1000 个字符，以及它所在窗口的标题，从中取出最多 40 个名字和少见词，比如 Quorvia、甄若岚或 gRPC，放在个人词库前面交给语音模型，让写在那里的名字按同样的写法写出来。文字本身从不交给模型。在 2026 年 10 月 15 日和 16 日测试的片段上，说出的名字就在屏幕上时，按那次测试的算法，201 个名字写对的从 107 个升到 161 个，真人录音里 81 个从 59 个升到 70 个，其余文字没有变差。已知风险：屏幕上有一个和你说的另一个名字读音相近的名字时，Orra 可能写成屏幕上的那个。真人录音里，不开时写对的 59 个名字有 13 个因此写错，所以默认关闭。它在 macOS 能读取文字的 App 里有效，从不读取密码框和密码管理器。在聊天或回复邮件时，对话内容和引用的原邮件不在光标前面，所以只用到你已经输入的文字和窗口标题。如果模型写出一串名字盖掉了你说的话，Orra 会粘贴不带名字时听到的内容。
- **语气词和数字。** 粘贴之前，Orra 会去掉只用来停顿的语气词，比如“呃”“额”“um”“uh”，有意义的词会保留，比如“好啊”“吧”“那个”。它还会在读者期待阿拉伯数字的地方把中文数字写成数字：“二零二六年十月十号”写成“2026年10月10号”，“百分之五十”写成“50%”，“Lexus RX 三五零”写成“Lexus RX 350”。“三本书”这样的小数目、约数和成语保持原样。两项都可以在“设置 → 通用 → 整理文字 → 选项…”里关闭。
- **用本地模型整理文字。** 新用户在内存 16 GB 及以上的 Mac 上点按欢迎窗口里的“下载模型”时，会一并下载它的模型（Qwen3.5 4B，3.05 GB），并打开整理功能。其他情况下默认关闭，在“设置 → 通用”里打开“整理文字”后，Orra 会先询问是否下载这个模型。在“整理文字”里也可以关闭它。Orra 在语气词和数字规则之后，在你的 Mac 上运行这个模型。它会去掉规则漏掉的语气词，比如当作停顿用的“那个”“就是说”，并按你说出口的更正改好内容，比如“三点，哦不对，四点”或“Monday, I mean Tuesday”。模型加载后约占 4 GB 内存。15 分钟没有听写时，Orra 会把它从内存中卸载，只打开翻译时也一样，下次按下说话键或翻译键时，它会在你说话的同时重新加载。在 M5 Pro 上，短的听写多花 0.6 到 1 秒，400 个汉字的听写多花 3 到 6 秒，较慢的 Mac 会更久。超过 400 个字符的听写不整理，直接粘贴，其中有语气词或更正时会提示。如果整理结果看起来像是在回答问题或执行请求，或者加了词或数字，Orra 会放弃这次整理，粘贴未经整理的文字，模型用时太久时也一样。这些检查是经验规则，整理仍可能改变你的原意，这时可以用 Orra 菜单里的“粘贴原文”找回整理之前的文字。在手写的测试听写上，178 条整理中有 156 条与预期完全一致。在 70 条要求模型做事的听写上，没有一条被执行。
- **翻译。** 默认关闭，在“设置 → 通用 → 功能”里打开“翻译”。翻译键在同一页的“按键”里，打开翻译后才能使用。它使用整理模型，即使整理文字关闭也能用。模型不在这台 Mac 上时，会先询问是否下载。按住翻译键（默认是右侧 Option 键，可以更换，说话键是右侧 Option 键时默认是右侧 Command 键）说话，松开后 Orra 会粘贴译文：中文翻译成英文，英文翻译成中文，也可以在“翻译”开关正下方的“翻译成”里固定翻译成其中一种。翻译成中文时，PR、iPhone 这类常用英文词可能保留英文。翻译键要按住 0.3 秒才算按下，所以 Option 快捷键和右侧 Option 键输入的字符照常可用。翻译键是右侧的键或 fn 键时，按下就会启动麦克风，等按键算作按下、麦克风也传来声音后，才播放开始提示音，提示音之后说的话都会录下来。在这 0.3 秒里按了快捷键，录音会立即丢弃，不过 macOS 可能会短暂显示橙色麦克风标志。快速连按两下翻译键，就能免手持翻译。录音时，音量条旁边会显示一个小标记：“译”，固定语言时显示“EN”或“中”。如果把说话键选作翻译键，或者反过来，两个键会互换，设置里会说明。超过 300 个字符的听写，以及没通过 Orra 检查或用时太长的译文，都会按你说的原话粘贴，所以你说的话不会丢。“粘贴原文”可以找回翻译之前的文字，“拷贝上次听写”拷贝的是译文，Orra 也不会从翻译后粘贴的文字中学习更正。在 M5 Pro 上，模型载入后，翻译一条短的听写大约需要三分之一秒。模型卸载后，按住时间很短的听写可能要等它加载完。
- **会议同传。** 0.4.0 新增。开关在“设置 → 会议同传”页面里，也在 Orra 菜单的“会议同传”标题下，在菜单里点一下就能打开实时字幕。
  - **实时字幕**每次启动 Orra 时都是关闭的。它捕获 Mac 播放的声音，从不使用麦克风，并在一个浮动窗口里逐句显示由本地模型翻译的字幕，可以只显示译文，也可以原文和译文逐句对照，在窗口里或设置里选择。有人开始说话大约一秒后，开头的几个词就会以灰色小字显示，并随着他说下去不断增加。一句话说完后，最终的文字会替换这一行，译文随后出现。macOS 会询问一次，请在“录屏与系统录音”中允许 Orra。没有本地模型时，窗口先显示原话，直到你下载模型。关闭窗口就会关闭字幕。字幕只保存在内存中，关闭后就消失。
  - **为对方朗读译文**需要先在“设置 → 通用”里打开“翻译”。用翻译键说的话翻译后，还会由你 Mac 上的语音合成模型 Qwen3-TTS（约 2 GB，需要下载）读出来，送到一个输出设备：你选的设备，或者已安装时的 Orra Microphone，从不会自己送到扬声器。在通话 App 里把 Orra Microphone 选作麦克风，通话另一方就能听到译文。没有 Orra Microphone 时，可以选一个通话 App 能当作麦克风使用的设备，比如回环设备。Orra 会一条接一条地朗读译文，你听写时会先等待。默认也会粘贴译文。使用声音样本时，每句话播放前都会先检查。想让它用你的音色说话，可以点按“声音样本”旁的“录音…”，读出一段约 10 秒的短文，也可以在那里导入音频文件。Orra 把样本保存在内存中，退出即清除。打开“记住我的音色”（默认关闭）后，Orra 会把样本的音频保存在 ~/Library/Application Support/io.github.db-ol.Orra/Voice，从不保存样本里说的话，也不进入备份，直到你移除它或关闭这个开关。Orra 重新打开后，会在“为对方朗读译文”打开时自动载入它。请只用你自己的声音，并告诉对方他们听到的是合成的声音。Orra Microphone 是一个单独的音频驱动，不在 Orra.dmg 里。从 0.4.0 版本下载已签名并经过公证的 [OrraMicrophone.pkg](https://github.com/db-ol/Orra/releases/download/v0.4.0/OrraMicrophone.pkg)，打开即可安装。[Drivers/OrraMicrophone](../Drivers/OrraMicrophone/README.md)（英文）说明了如何移除它，或者自己构建。
- **听写语言。** 在“设置 → 通用 → 听写”的“听写语言”里，选择你除英文之外说的语言：“中文（普通话和粤语）+ English”“日本語 + English”或“Español + English”，后两种是测试版。一句话里可以混说这两种语言。英文总是其中之一，不能再加第三种。欢迎窗口里也有同样的选择。新用户的 Mac 首选语言是日语时，默认是“日本語 + English”，是西班牙语时默认是“Español + English”，其他情况默认是“中文 + English”。用早期版本设置过 Orra 的用户会保持“中文 + English”，直到自己改选。
  - **中文**包括普通话和粤语。粤语用简体字输出，会保留“嘅”“咗”这类粤语用字，“係”会写成“系”。在公开的粤语录音上，字错误率是 4.8% 到 5.7%，和普通话相近。语气词规则会保留粤语里当动词用的“呃”（骗）。数字规则、整理和翻译都是为普通话设计的，没有在粤语上测过，粤语和英文混说也没有测过。
  - **日语或西班牙语。** 这种语言的句子按语音模型写出的原文粘贴，日语会保留汉字，比如“東京駅”。语气词和数字规则、整理和从修改中学习都是为中文和英文设计的，所以不会处理这类句子，翻译时也从听到的原文开始。英文句子照常经过这些步骤。语音模型写成别的语言时，比如把西班牙语写成了中文，Orra 会先用你选的语言、再用英文重新转写。只在你确实用日语或西班牙语听写时才选它们。选日语时，只有汉字的句子也算日语，因为单凭汉字分不出日语和中文，所以中文语音不再经过为中文设计的步骤。选西班牙语时，中文语音会被当成语音模型选错了语言，大多会被译成西班牙语。在朗读的测试语音上，西班牙语的词错误率是 3.0%，日语的字错误率是 6.3%，一句话的转写时间中位数是 0.4 秒。选“中文 + English”时，Orra 会把同样的语音当成语音模型选错了语言，重新转写一遍：转写时间中位数是 1.2 秒和 1.1 秒，错误率是 12.4% 和 15.4%，还有 6% 的西班牙语句子和 11% 的日语句子被粘贴成了中文或英文译文。
  - 实时字幕也按这个选择处理，从下一句开始生效。
- **麦克风。** Orra 默认使用系统的输入设备，也可以在“麦克风”里选择别的。MacBook 合上盖子时内置麦克风会关闭，这时请选择其他麦克风，比如摄像头上的。
- **提示音、屏幕提示和程序坞图标。** 在“设置 → 通用 → 听写”里可以关闭提示音，并选择屏幕提示：“始终显示”会在听写时显示音量条，在 Orra 待命时显示小横条，“仅在听写时显示”不显示小横条，“不显示”则两者都不显示。程序坞图标在“设置 → 通用 → 系统”里关闭。
- **界面语言。** Orra 的菜单和窗口有英文、简体中文、日文和西班牙文，默认跟随你的 Mac。西班牙文用的是拉丁美洲西班牙文，Mac 设为西班牙地区的西班牙文时也是这样。要换成另一种，在欢迎窗口的“语言”或“设置 → 通用 → 系统”的“界面语言”里选择，再重新启动 Orra。在欢迎窗口里选择后，点按“完成”时 Orra 会自动重新启动，除非“设置”或 Orra 的其他窗口还开着，或者模型还在下载。
- **更新。** 在菜单里选择“检查更新…”，或者在“设置 → 关于”里让 Orra 自动检查，那里也显示版本。
- **报告问题。** 在 Orra 的菜单里选择“报告问题…”，写下发生了什么，再点“在 GitHub 上继续”。浏览器会打开一个新问题，你写的内容、Orra 版本、macOS 版本和 Mac 型号都已填好。需要一个免费的 GitHub 账号，问题会公开显示。Orra 还会生成一份诊断报告，你可以把它拖进问题页面。
