# Orra 使用指南

Orra 的概览和下载见 [README](../README.zh-CN.md)，隐私的详细说明见 [privacy.zh-CN.md](privacy.zh-CN.md)。

## 开始使用

1. 打开 Orra，欢迎窗口里有个小向导，会告诉你下一步做什么，带你完成四步。先在窗口顶部选择 Orra 的语言：English、简体中文、日本語、Español，或跟随 Mac 系统，窗口会立即换成这种语言。下面再选择你听写用的语言，见下文的“听写语言”。在你选择之前，它会跟着上面选的语言变化。之后可以在“设置 → 通用”里更改 Orra 的语言，在“设置 → 听写”里更改听写语言。前三步让 Orra 可以使用，最后一步可以跳过：
   - **下载模型**，只需一次。内存 16 GB 及以上的 Mac 上，点按“下载模型（5.52 GB）”会先下载语音模型（2.47 GB），再下载用来整理你说的话的第二个本地模型（3.05 GB），共用一个进度条，并打开整理功能。语音模型装好后就可以听写。整理模型运行时约占 4 GB 内存，可以在“设置 → 听写”的“用本地模型整理文字”里关闭整理。内存更小的 Mac 上，这一步只下载语音模型，之后可以在“设置 → 听写”里打开整理功能。
   - **允许使用麦克风。**
   - **允许辅助功能**，Orra 需要它来识别说话键和粘贴文字。系统设置打开后，旁边会出现一张小卡片，用动画演示在哪里打开 Orra。在列表里打开 Orra 后，卡片会自动消失。如果你之前拒绝了麦克风权限，点按麦克风这一步的“打开麦克风设置…”后，系统设置旁边也会出现类似的卡片。
   - **选择说话键**，按一下你想用的键就行。用 Mac 自带的键盘时，左下角的 fn（地球仪）键在右手用鼠标时很顺手。用外接键盘时，右侧 Control 键最合适，因为有些外接键盘（比如 Logitech MX Keys）的 fn 键信号根本传不到 Mac。如果两种键盘换着用，可以在设置里把另一个键加为第二个说话键，见下面的“按键”。在说话键下面选它的用法：新用户默认是“按一下开始，再按一下结束”，也可以选“按住”或“连按两下”。
2. 按一下说话键（默认是右侧 Control 键，可以更换）开始说话，说完再按一下，文字会出现在光标所在的位置。用法选“按住”时，说话时一直按住这个键，松开就结束。选“连按两下”时，快速连按两下开始。麦克风开始传来声音时，Orra 会播放开始提示音，提示音之后说的话都会录下来。说话时，屏幕底部的深色小胶囊里有一排白色音量条随你的声音跳动（可以在设置里关掉），菜单栏里会出现 macOS 的橙色麦克风标志。
3. Orra 在菜单栏和程序坞里，其他功能都在它的菜单和设置里。Orra 准备就绪后，欢迎窗口会显示“还可以试试”：整理、翻译和会议同传，在内存 16 GB 或以上的 Mac 上还有“项目”，还没打开的功能旁边有一个按钮，可以直接打开设置里它所在的页面。要再次打开欢迎窗口，在 Orra 准备就绪之前选择 Orra 菜单里的“设置向导…”，准备就绪后选择“入门指南…”。Orra 准备就绪后，打开 Orra 或点按它的程序坞图标都会显示设置窗口。如果在“设置 → 通用 → 系统”里打开了“登录时打开”，那么无论是登录时自动打开，还是你自己打开，Orra 都不显示窗口，但点按程序坞图标仍会显示设置窗口。

## 使用说明

- **按键。** 说话键和翻译键都在“设置 → 通用 → 按键”里。点按键的输入框（或“更改…”），再按你想用的键：fn（地球仪）键，左侧或右侧的 Control、Option、Command 键，或者组合键，比如同时按住 Control 和 Option，或者 Shift Command D。不同键盘上同一个键的叫法不一样，所以输入框会显示 Mac 上的名称和符号，Option 和 Command 键还会注明 Windows 布局键盘上印的名称，比如“⌥ 右侧 Option 键（Alt）”“⌘ 右侧 Command 键（Windows 键）”。菜单里的“说话键”会显示当前的键，并能打开设置里的“按键”来更改。每个键都可以选用法：“按住”“按一下开始，再按一下结束”或“连按两下”。新用户的说话键默认是“按一下开始，再按一下结束”。用旧版本设置好的说话键仍是“按住”，直到你改选其他用法。翻译键默认也是“按一下开始，再按一下结束”，但如果你在旧版本里打开过翻译，它仍是“按住”，直到你改选其他用法。用“按住”时，左侧的 Control、Option、Command 键要单独按住片刻才开始录音。用“按一下开始，再按一下结束”时，快速按一下这些键，松开时开始录音。两种情况下，它们的快捷键都照常可用。Shift 键、大写锁定键和会输入文字的键不能单独作为按键，macOS 或大多数 App 用到的快捷键，比如 Command C 或 Control Space，也不能选。输入框会说明原因，以及可以用哪些键。组合键里的普通键不会输入到前台的 App，单按它照常打字。说话键下面的“第二个键”可以再加一个单独的键，用法和说话键完全相同，比如在 fn 键之外加上右侧 Control 键。换用 fn 键传不到 Mac 的外接键盘时，这样很方便。说话键是 fn 键、又没有第二个键时，接上外接键盘后 Orra 会提示添加一次。如果旧版本里同时开了几个说话键，Orra 会保留一个：优先 fn 键，其次右侧 Control 键，然后是其他右侧的键，最后是左侧的键。“按键”的最后一项是“实时字幕快捷键”，在任何 App 中都能用它打开或关闭实时字幕，不需要任何权限。不论使用哪种键盘布局，它默认都是 Control Option Command C（⌃ ⌥ ⌘ C）。如果 Orra 加入这个快捷键时，你的说话键或翻译键正好是这个组合，或者是只由它的修饰键组成的组合，比如 Control 和 Option，它就默认为“无”。要更改，点它的输入框，再按一个带 Control 或 Command 的键，或者 F13 这样的功能键。只用 Option，或只用 Option 和 Shift 不行，因为 macOS 会拒绝。点“无”可以关闭它。如果 macOS 拒绝了这个快捷键，比如因为其他 App 已在使用它，设置里会提示。它不能和 Orra 的按键相同，Orra 的按键也不能和它相同。如果某个按键是只由快捷键里的修饰键组成的组合，比如 Control 和 Option，按快捷键时可能会短暂开始一次听写，设置里会提示。说话键是右侧的键（比如右侧 Control 键）时，如果先按下它，也会这样，所以请用左手按快捷键。
- **免手持模式。** 按键用“按住”时，快速连按两下，松开后继续说。屏幕底部的指示条会提示按哪个键结束，按一下就会粘贴，按 Esc 键则取消。每次最多录 5 分钟，见下面的“长听写”。可以在“设置 → 通用 → 按键”里用它的开关关闭连按两下，这个开关只在某个键的用法是“按住”时显示。
- **长听写。** 不论用哪种方式开始，每次最多录 5 分钟。最后 15 秒，指示条会倒数秒数，停止后会说明原因。超过 1 分钟的录音会在停顿处切成每段不超过 1 分钟，你松开后 Orra 逐段转写。在 M5 Pro 上，每分钟语音大约要等 2 秒，中文加上个人词库时最多再翻一倍。有一段无法转写时，Orra 会粘贴其余部分，并提示你。超过 400 个字符的听写不整理，超过 300 个字符的不翻译，这样直接粘贴时 Orra 也会提示。在免手持模式、“按一下开始，再按一下结束”和“连按两下”里，你想用来结束录音的那一下，可能在上限停止录音之后才按。所以在提示消失之前（提示出现后 30 秒），再按一下那个键只会关掉提示，不会开始新的录音。按键用“按住”时，按住不放照常录音，快速连按两下也照常开始免手持模式。
- **个人词库。** 在“设置 → 个人词库”里添加你常用的词和名字。每次听写，Orra 会把你最近添加或用过的 200 个词提供给语音模型，因为列表越长，每个词的帮助越小，每次听写也越慢。在测试语音上，这些词的正确率中文从约 84% 提高到 99%，英文从 83% 提高到 96%，而且没说到的词几乎不会被凭空加进来。词库最多可以放 5000 个词，这个上限只是为了防止数据失控。表格里显示每个词是你添加的还是 Orra 学到的、Orra 曾把它听成什么，以及你上次用到它的时间。
- **从你的修改中学习。** 在“设置 → 听写 → 识别”里打开“从我的修改中学习”。听写后你马上改正了一个听错的词，Orra 会把你的写法加入个人词库，并弹出提示，你可以撤销。去掉或加上单词之间的空格也算，比如把 read me 改成 readme。如果你只改了名字里的一个汉字，比如把“林悦”改成“霖悦”，Orra 会先询问你，并给出它猜的完整词语，你可以修改后再添加。之后的听写里，如果语音模型还是写成听错的样子，Orra 会换成你的写法，前提是学习开着、这个词还在个人词库里。只由普通词组成的听错写法（比如把 there 改成 their）从不替换。把听错的写法改回去，就不再替换。从个人词库删掉的词，下次再改正时会重新学到，点过“撤销”的词则不会。学习在 macOS 能读取文字的 App 里有效，比如备忘录、邮件和 Safari。在其他 App 里，可以拷贝这个词，再从 Orra 的菜单里添加。
- **使用屏幕上的名字（测试版）。** 默认关闭，在“设置 → 听写 → 识别”里打开“使用屏幕上的名字（测试版）”。每次开始听写时，Orra 会读取你听写的输入框里光标前最多 1000 个字符，以及它所在窗口的标题，从中取出最多 40 个名字和少见词，比如 Quorvia、甄若岚或 gRPC，放在个人词库前面交给语音模型，让写在那里的名字按同样的写法写出来。文字本身从不交给模型。在 2026 年 10 月 15 日和 16 日测试的片段上，说出的名字就在屏幕上时，按那次测试的算法，201 个名字写对的从 107 个升到 161 个，真人录音里 81 个从 59 个升到 70 个，其余文字没有变差。已知风险：屏幕上有一个和你说的另一个名字读音相近的名字时，Orra 可能写成屏幕上的那个。真人录音里，不开时写对的 59 个名字有 13 个因此写错，所以默认关闭。它在 macOS 能读取文字的 App 里有效，从不读取密码框和密码管理器。在聊天或回复邮件时，对话内容和引用的原邮件不在光标前面，所以只用到你已经输入的文字和窗口标题。如果模型写出一串名字盖掉了你说的话，Orra 会粘贴不带名字时听到的内容。
- **语气词和数字。** 粘贴之前，Orra 会去掉只用来停顿的语气词，比如“呃”“额”“um”“uh”，有意义的词会保留，比如“好啊”“吧”“那个”。它还会在读者期待阿拉伯数字的地方把中文数字写成数字：“二零二六年十月十号”写成“2026年10月10号”，“百分之五十”写成“50%”，“Lexus RX 三五零”写成“Lexus RX 350”。“三本书”这样的小数目、约数和成语保持原样。两项都可以在“设置 → 听写 → 整理文字”里关闭。
- **用本地模型整理文字。** 新用户在内存 16 GB 及以上的 Mac 上点按欢迎窗口里的“下载模型”时，会一并下载它的模型（Qwen3.5 4B，3.05 GB），并打开整理功能。其他情况下默认关闭，在“设置 → 听写”里打开“用本地模型整理文字”后，Orra 会先询问是否下载这个模型。用同一个开关也可以关闭它。Orra 在语气词和数字规则之后，在你的 Mac 上运行这个模型。它会去掉规则漏掉的语气词，比如当作停顿用的“那个”“就是说”，并按你说出口的更正改好内容，比如“三点，哦不对，四点”或“Monday, I mean Tuesday”。模型加载后约占 4 GB 内存。15 分钟没有听写时，Orra 会把它从内存中卸载，只打开翻译时也一样，下次按下说话键或翻译键时，它会在你说话的同时重新加载。在 M5 Pro 上，短的听写多花 0.6 到 1 秒，400 个汉字的听写多花 3 到 6 秒，较慢的 Mac 会更久。超过 400 个字符的听写不整理，直接粘贴，其中有语气词或更正时会提示。如果整理结果看起来像是在回答问题或执行请求，或者加了词或数字，Orra 会放弃这次整理，粘贴未经整理的文字，模型用时太久时也一样。这些检查是经验规则，整理仍可能改变你的原意，这时可以用 Orra 菜单里的“粘贴原文”找回整理之前的文字。在手写的测试听写上，178 条整理中有 156 条与预期完全一致。在 70 条要求模型做事的听写上，没有一条被执行。
- **翻译。** 默认关闭，在“设置 → 翻译”里打开“翻译”。翻译键在“设置 → 通用 → 按键”里，打开翻译后才能使用。它使用整理模型，即使整理文字关闭也能用。模型不在这台 Mac 上时，会先询问是否下载。按一下翻译键（默认是右侧 Option 键，可以更换，说话键是右侧 Option 键时默认是右侧 Command 键）开始说话，再按一下结束，Orra 会把你说的话在英文和你的听写语言之间翻译后粘贴：中文翻译成英文，英文翻译成中文，听写语言是日语或西班牙语时也一样，这时韩文等用其他文字写的内容翻译成英文。用“按住”时，则是按住翻译键说话，松开结束。也可以在“翻译成”里，让所有内容都以英文或你的听写语言粘贴。为另一种听写语言做的选择会保留下来，换回那种语言时再生效，在此之前按“自动”处理。翻译成中文、日语或西班牙语时，PR、iPhone 这类常用英文词可能保留英文。翻译键要按住 0.3 秒才算按下（用“按一下开始，再按一下结束”时，不到 0.3 秒就松开，则在松开时算按下），所以 Option 快捷键和右侧 Option 键输入的字符照常可用。翻译键是右侧的键或 fn 键时，按下就会启动麦克风，等按键算作按下、麦克风也传来声音后，才播放开始提示音，提示音之后说的话都会录下来。在这 0.3 秒里按了快捷键，录音会立即丢弃，不过 macOS 可能会短暂显示橙色麦克风标志。用“按住”时，快速连按两下翻译键，就能免手持翻译。用“按一下开始，再按一下结束”时，单独轻按一下翻译键也会开始录音，直到再按一下才结束，误按时按 Esc 键取消即可。录音时，音量条旁边会显示一个小标记：“译”，固定语言时显示“EN”或“中”。听写语言是日语时显示“訳”“EN”或“日”，是西班牙语时显示“⇄”“EN”或“ES”。如果把说话键选作翻译键，或者反过来，两个键会互换，设置里会说明。超过 300 个字符的听写，以及没通过 Orra 检查或用时太长的译文，都会按你说的原话粘贴，所以你说的话不会丢。“粘贴原文”可以找回翻译之前的文字，“拷贝上次听写”拷贝的是译文，Orra 也不会从翻译后粘贴的文字中学习更正。在 M5 Pro 上，模型载入后，翻译一条短的听写大约需要三分之一秒。模型卸载后，很短的听写也可能要等它加载完。
- **会议同传。** 0.4.0 新增。开关在“设置 → 会议同传”页面里，也在 Orra 菜单的“会议同传”标题下，在菜单里点一下就能打开实时字幕。
  - **实时字幕**每次启动 Orra 时都是关闭的。它捕获 Mac 播放的声音，从不使用麦克风，并在一个浮动窗口里逐句显示字幕。在窗口顶部或设置里可以选择显示“原文”“译文”或“双语”。“译文”和“双语”由本地模型逐句翻译。“原文”只显示说的原话，不翻译，所以不会加载或下载本地模型。选择“原文”期间听到的句子，切换后也不会再翻译。有人开始说话大约一秒后，开头的几个词就会以灰色小字显示，并随着他说下去不断增加。一句话说完后，最终的文字会替换这一行，译文随后出现。字幕有单独的语言设置“字幕翻译成”，在窗口顶部“原文”“译文”“双语”的旁边，也在“设置 → 会议同传”里。翻译键的“翻译成”不会改变它。可选英文和你的听写语言。它一开始是你自己的语言：Orra 显示简体中文、日本語或 Español 时就是这种语言，否则是 Mac 语言列表里排在最前面的中文、日语或西班牙语，都没有时是英文。如果它既不是英文也不是你的听写语言，字幕使用你的听写语言。如果你用早期版本设置过 Orra，它一开始是你在“翻译成”里固定的语言，没有固定时是你的听写语言。已经是所选语言的句子按原话显示，所以用听写语言开的会不再翻译成英文，除非你选择英文。其他句子都翻译成所选语言。两种语言都不是的句子翻译成英文，比如听写语言是中文时的日语，或听写语言是日语时的中文。为另一种听写语言做的选择会保留下来，换回那种语言时再生效，在此之前字幕使用你的听写语言。新的选择从下一句开始生效。选择“原文”时这一项不可用，因为“原文”不翻译。macOS 会询问一次，请在“录屏与系统录音”中允许 Orra。没有本地模型时，窗口先显示原话，直到你下载模型。关闭窗口就会关闭字幕。在任何 App 中按实时字幕快捷键都能打开或关闭字幕，它默认是 Control Option Command C，可以在“设置 → 通用 → 按键”里更改。字幕只保存在内存中，退出 Orra 之前一直保留，所以关闭后仍然可以拷贝。窗口右上角的“拷贝全部字幕”按钮会按窗口的显示方式拷贝每一句字幕，点按它的箭头会打开一个菜单，里面有“拷贝原文”“拷贝译文”和“拷贝原文和译文”。还没说完、以灰色小字显示的那一行不会被拷贝。关闭窗口后，也可以用 Orra 菜单里的“拷贝字幕”拷贝。再次打开字幕时，窗口从空白开始，上一次会议的字幕保留在“拷贝上一次的字幕”里。和“拷贝上次听写”一样，这样拷贝的内容只留在这台 Mac 的剪贴板上。
  - **为对方朗读译文**需要先在“设置 → 翻译”里打开“翻译”。用翻译键说的话翻译后，还会由你 Mac 上的语音合成模型 Qwen3-TTS（约 2 GB，需要下载）读出来，送到一个输出设备：你选的设备，或者已安装时的 Orra Microphone，从不会自己送到扬声器。在通话 App 里把 Orra Microphone 选作麦克风，通话另一方就能听到译文。没有 Orra Microphone 时，可以选一个通话 App 能当作麦克风使用的设备，比如回环设备。Orra 会一条接一条地朗读译文，你听写时会先等待。它能朗读英文、中文、日语和西班牙语的译文，录声音样本时读的短文是英文或你的听写语言。有些版本在“语音合成模型”里还提供 CosyVoice3，它不会说日语，所以用它时 Orra 不播放日语译文，而是说明原因，即使关闭了“同时粘贴译文”也会粘贴这条译文。默认也会粘贴译文。使用声音样本时，每句话播放前都会先检查。想让它用你的音色说话，可以点按“声音样本”旁的“录音…”，读出一段约 10 秒的短文，也可以在那里导入音频文件。Orra 把样本保存在内存中，退出即清除。打开“记住我的音色”（默认关闭）后，Orra 会把样本的音频保存在 ~/Library/Application Support/io.github.db-ol.Orra/Voice，从不保存样本里说的话，也不进入备份，直到你移除它或关闭这个开关。Orra 重新打开后，会在“为对方朗读译文”打开时自动载入它。请只用你自己的声音，并告诉对方他们听到的是合成的声音。Orra Microphone 是一个单独的音频驱动，不在 Orra.dmg 里。从 0.4.0 版本下载已签名并经过公证的 [OrraMicrophone.pkg](https://github.com/db-ol/Orra/releases/download/v0.4.0/OrraMicrophone.pkg)，打开即可安装。[Drivers/OrraMicrophone](../Drivers/OrraMicrophone/README.md)（英文）说明了如何移除它，或者自己构建。
- **听写语言。** 在“设置 → 听写”的“听写语言”里，选择你除英文之外说的语言：“中文（普通话和粤语）+ English”“日本語 + English”或“Español + English”，后两种是测试版。一句话里可以混说这两种语言。英文总是其中之一，不能再加第三种。欢迎窗口里也有同样的选择。新用户默认使用自己的语言：Orra 显示简体中文、日本語或 Español 时就是这种语言，否则是 Mac 语言列表里排在最前面的中文、日语或西班牙语。所以 Mac 的语言列表里英文排第一、日语排第二时，默认是“日本語 + English”，日语 Mac 把 Orra 设为 English 时也一样。都没有时默认是“中文 + English”。第一次设置 Orra 时，在你选择听写语言之前，它会跟着你在欢迎窗口里为 Orra 选的语言变化。之后它不会自己改变，以后更改 Orra 的语言也不会。用早期版本设置过 Orra 的用户会保持“中文 + English”，直到自己改选。
  - **中文**包括普通话和粤语。粤语用简体字输出，会保留“嘅”“咗”这类粤语用字，“係”会写成“系”。在公开的粤语录音上，字错误率是 4.8% 到 5.7%，和普通话相近。语气词规则会保留粤语里当动词用的“呃”（骗）。数字规则、整理和翻译都是为普通话设计的，没有在粤语上测过，粤语和英文混说也没有测过。
  - **日语或西班牙语。** 这种语言的句子按语音模型写出的原文粘贴，日语会保留汉字，比如“東京駅”。语气词和数字规则、整理和从修改中学习都是为中文和英文设计的，所以不会处理这类句子，翻译时也从听到的原文开始。翻译键会把这种语言的句子翻译成英文，只有假名的日语也一样，并把英文翻译成这种语言。“翻译成”固定为这种语言时，已经是这种语言的句子按原话粘贴。英文句子照常经过这些步骤。语音模型写成别的语言时，比如把西班牙语写成了中文，Orra 会先用你选的语言、再用英文重新转写。只在你确实用日语或西班牙语听写时才选它们。选日语时，只有汉字的句子也算日语，因为单凭汉字分不出日语和中文，所以中文语音不再经过为中文设计的步骤。选西班牙语时，中文语音会被当成语音模型选错了语言，大多会被译成西班牙语。在朗读的测试语音上，西班牙语的词错误率是 3.0%，日语的字错误率是 6.3%，一句话的转写时间中位数是 0.4 秒。选“中文 + English”时，Orra 会把同样的语音当成语音模型选错了语言，重新转写一遍：转写时间中位数是 1.2 秒和 1.1 秒，错误率是 12.4% 和 15.4%，还有 6% 的西班牙语句子和 11% 的日语句子被粘贴成了中文或英文译文。
  - 实时字幕也按听写语言判断每一句，从下一句开始生效，“字幕翻译成”里可选的也是听写语言和英文。
- **麦克风。** Orra 默认使用系统的输入设备，也可以在“麦克风”里选择别的。MacBook 合上盖子时内置麦克风会关闭，这时请选择其他麦克风，比如摄像头上的。
- **提示音、屏幕提示和程序坞图标。** 在“设置 → 通用 → 系统”里可以关闭提示音，并选择屏幕提示：“始终显示”会在听写时显示音量条，在 Orra 待命时显示小横条，“仅在听写时显示”不显示小横条，“不显示”则两者都不显示。程序坞图标也在这里关闭。
- **界面语言。** Orra 的菜单和窗口有英文、简体中文、日文和西班牙文，默认跟随你的 Mac。西班牙文用的是拉丁美洲西班牙文，Mac 设为西班牙地区的西班牙文时也是这样。要换成另一种，在欢迎窗口的“语言”或“设置 → 通用 → 系统”的“界面语言”里选择，再重新启动 Orra。在欢迎窗口里选择后，点按“完成”时 Orra 会自动重新启动，除非“设置”或 Orra 的其他窗口还开着，或者模型还在下载。
- **更新。** 在菜单里选择“检查更新…”，或者在“设置 → 关于”里让 Orra 自动检查，那里也显示版本。
- **报告问题。** 在 Orra 的菜单里选择“报告问题…”，写下发生了什么，再点“在 GitHub 上继续”。浏览器会打开一个新问题，你写的内容、Orra 版本、macOS 版本和 Mac 型号都已填好。需要一个免费的 GitHub 账号，问题会公开显示。Orra 还会生成一份诊断报告，你可以把它拖进问题页面。报告“项目”的问题时，请描述操作步骤，不要写入邮件正文、姓名、电子邮件地址，也不要附上邮件截图。问题页面的“功能”一项可以选择“项目（预览版）”。

## 项目（预览版）

“项目”是 Orra 的可选功能，用来处理你的邮件和项目文件夹，目前是预览版，以后还可能变化。它读取你选择的“邮件”邮箱中的邮件，以及你添加到项目里的文件夹中的文件。它把每封新邮件归入它的项目，并在你需要时结合项目资料解释一封邮件、注明出处，再起草回复。它使用你 Mac 上的整理模型，需要内存 16 GB 及以上的 Mac，从不发送、移动或删除邮件。它读取和保存什么，见 [privacy.zh-CN.md](privacy.zh-CN.md)。

- **打开“项目”。** 在“设置 → 项目”里打开“项目”。它要配合这台 Mac 上的“邮件” App 使用，所以请先确认你的邮件能在“邮件”中看到。如果你的 Mac 上还没有整理模型，Orra 会先问你，再下载它（3.05 GB）。如果整理模型在你的 Mac 上但无法载入，页面会显示“无法载入”，点按“重新载入”可以再载入一次。打开“项目”后还不会读取任何东西。开关下面的“开始使用‘项目’”列出了要做的几步，每完成一步就打上勾：下载整理模型（下载时可以继续做后面的步骤）、打开“邮件” App、允许访问“邮件”、选择邮箱并开始读取，以及按需创建第一个项目。“项目”关闭时，你也可以在欢迎窗口的“还可以试试”里，以及 Orra 菜单的“设置‘项目’…”中找到它。“隐私说明”旁边的“如何使用‘项目’”会打开本指南。
- **“邮件”访问权限。** 点按“打开‘邮件’”会打开“邮件” App。只有你点按“打开‘邮件’”时，Orra 才会打开“邮件”。“允许访问‘邮件’…”要在“邮件”打开后才能使用。Orra 会先说明它读取什么，点按“继续”后，macOS 会问你是否允许 Orra 控制“邮件”，请点按“允许”。“项目”只在“邮件”打开时读取邮件。如果你没有允许，页面会提示你，点按“打开自动化设置…”可以前往“隐私与安全性”的“自动化”，在那里打开 Orra 下面的“邮件”。在“邮件”关闭时再次打开 Orra，Orra 还无法知道它是否仍可读取“邮件”，所以页面会显示“打开‘邮件’”，打开后即可检查访问权限。
- **邮箱。** 在“选择邮箱并开始读取”这一步里，勾选“项目”要读取的邮箱。在你更改之前，“收件箱（所有帐户）”和“已发送（所有帐户）”是勾选的，每个帐户的邮箱和“我的 Mac 上”的邮箱列在各自的名称下面。“时间范围”决定读取多久以前的邮件：最近 30、90、180 或 365 天，默认 90 天。在允许访问“邮件”并勾选至少一个邮箱之前，“开始读取邮件”不可用，旁边的说明会告诉你还缺哪一项。在你点按“开始读取邮件”之前，不会读取任何邮件，点按后还会打开“项目”窗口。之后，同样的列表会显示在“邮箱”下面，更改邮箱或时间范围会立即生效，但只影响“项目”之后读取的邮件。已保存的邮件会一直保留，直到过期或你删除“项目”的数据。你关联到项目的邮箱也会列在这里，注明是为哪个项目读取的，旁边有“编辑项目…”。不管是否勾选，“项目”都会读取它。“邮件”打开时，“项目”每分钟查看一次有没有新邮件。
- **“项目”窗口。** 用“打开‘项目’窗口”打开它：它在“设置 → 项目”里（点按“开始读取邮件”之前在“开始使用‘项目’”的最后一步里，之后在页面顶部），也在菜单栏的 Orra 菜单里（那里还会显示有多少封邮件等你回复），以及 Orra 程序坞图标的菜单里。窗口左边是“待归入项目”“已搁置”、Orra 建议的项目和你的项目，中间是你所选那一项的邮件，右边是你选中的邮件，或者项目的页面。没有选中邮件，也没有显示项目页面时，右边会显示“如何使用‘项目’”：从选择邮箱到在“邮件”中回复的几个步骤，还有用来创建项目的“新建项目…”。选择邮箱的那一步和其中的“打开‘项目’设置…”（“邮件”关闭时还有“打开‘邮件’”），只在你点按“开始读取邮件”之前显示。窗口打开时，Orra 会显示在程序坞里，并让整理模型保持载入，关闭窗口就会释放它。邮件列表下面，或者列表为空时在列表中间，会有一行说明“项目”正在做什么，比如“正在读取邮件…”和已读取的封数，或者归类邮件时的“正在归类邮件…”。它也会说明为什么没有邮件进来：还没有选择邮箱、“邮件”没有打开、“邮件”响应缓慢、Orra 还无权读取“邮件”，或者部分邮件未能读取。需要时，这一行会带有“重试”“设置…”或“打开‘邮件’”。这台 Mac 上还没有整理模型时，列表下面会有一行说明，并带有“设置…”，下载时则显示下载进度。每个列表先显示最新的 1,000 封邮件，邮件更多时，列表下面会写明一共有多少封，并有“载入更早的邮件”。工具栏里的“解释‘邮件’中所选邮件”会显示并解释你在“邮件”里选中的邮件，前提是它在“项目”读取的邮箱里，而且在读取的时间范围内。它必须就是“项目”读取的那封邮件，发件人、收件人和日期都相同。
- **项目和文件夹。** 点按列表下面的“新建项目…”。给它起个名称，再写一段描述：项目是什么、对方是谁，以及对方用哪种语言写信。用“添加文件夹…”添加它的文件夹，或者把文件夹拖进来。“项目”会读取其中的 PDF、Word、RTF、OpenDocument、Markdown 和纯文本文件，每个项目最多 5,000 个文件，从不更改它们。它暂时不读取 Excel 和 PowerPoint 文件，会跳过不在这台 Mac 上的文件，比如没有下载的 iCloud 云盘文件，也从不读取你的个人文件夹、整个磁盘或“邮件” App 的本地数据文件。再添加项目的联系人和他们的电子邮件地址、角色，你们合作的公司的域名（比如 harbor.example），以及和项目关联的“邮件”邮箱，这个邮箱里的邮件总会归入这个项目。这些域名下的所有地址都算作项目联系人，他们的邮件会归入这个项目，回复给他们也算在项目之内。如果是 gmail.com 这类许多人共用的邮件服务，请改为在“联系人”中逐个添加，“新建项目”和“编辑项目”都不接受这类域名。项目的页面会显示“项目”读取了多少个文件、跳过了哪些以及原因，还有含隐藏文字的文件，“项目”会略过其中隐藏的文字。“编辑项目…”可以修改项目。
- **归类和规则。** “项目”会把新邮件归入它所在往来的项目、你设置的联系人、域名或规则所属的项目，或者关联邮箱所属的项目。如果这些都定不下来，“项目”窗口打开时由模型来选，它选的项目会标上“项目不确定”。哪个项目都不合适的邮件会放到“待归入项目”。订阅通讯和其他发给邮件列表或由机器发出的邮件会放到“已搁置”，除非其中有你项目的联系人。邮件顶部的标签会说明它为什么在这里。点按标签可以把邮件归入另一个项目，和列表快捷菜单里的“归入项目”一样，这封邮件在“邮件” App 里的位置不变。它的解释和草稿会一起删除，之后可以重新解释。如果你改过草稿，Orra 会先问你。你把同一个发件人或同一个域名的两封邮件归入同一个项目后，Orra 会提议添加一条规则，以后都把这类邮件归入那个项目。项目页面会列出它的规则，每条规则旁边都有“移除规则…”，移除后新邮件不再按这条规则归入项目，这条规则已归入的邮件仍留在项目中。你添加、编辑或移除项目，或者添加规则后，“项目”会重新归类这次改动涉及的邮件：“待归入项目”里的邮件、标着“项目不确定”且“项目”仍保留其文字的邮件、你添加或移除的联系人、域名和邮箱的邮件，以及你添加的规则所针对的发件人或域名的邮件。因为与这些邮件属于同一往来而归入项目的回复，也会重新归类。重新归类时，你自己归入的邮件、有草稿的邮件和你的规则归入的邮件都留在原处。标签里的“邮件中的联系人曾在此项目中有邮件往来”依据的是你自己归入这个项目的邮件，或者按项目的联系人、域名、规则或关联邮箱归入的邮件。因为与这些邮件属于同一往来而归入这个项目的回复也算在内。仅由模型选定项目的邮件不算在内。“需回复”标出等你回复的邮件，解释过的邮件还可能显示截止日期。
- **建议的项目。** 边栏在“待归入项目”和“已搁置”下面列出“建议的项目”，每个建议都会显示它会归入多少封邮件。Orra 会按往来和对方把“待归入项目”里的邮件分组，对方可以是一家公司的域名、使用 gmail.com 这类公共邮箱的个人，或者你用来归档邮件的“邮件”邮箱。剩下的往来会按主题里共有的词分组，比如一个活动的名称。你自己归入“待归入项目”的邮件、邮件列表的邮件，以及已有项目涵盖的邮件不计在内，最多显示 8 组，每组至少 3 封邮件。窗口打开时，模型会用这组邮件的语言给每组起名字，并用一句话描述它。点按一个建议，或者在它的菜单里选择“创建项目…”，会打开“新建项目”，名称、描述、联系人、域名和邮箱都已填好。你可以随意修改，添加文件夹后存储。也可以在这里或建议的菜单里选择“忽略此建议”，它就不会再出现。不经你点按，Orra 不会建立任何项目，你存储新项目后，它会重新归类邮件。
- **解释邮件。** 在你解释一封邮件之前，窗口会像“邮件”一样显示邮件本身：收件人和抄送、附件以及“项目”是否读取了附件的文字、发件人写的内容、每封转发的邮件和它自己的信头，以及收在“引用的文本”下面的引文。点按“解释”，模型会阅读这封邮件、它所在的往来、项目里的其他邮件、附件的文字，以及项目文件中相关的段落。Orra 的语言是中文时，解释用中文，其他语言时用英文。“重新解释”会重新解释一遍。如果你改过草稿，点按“重新解释”时，或者对解释过的邮件点按“解释‘邮件’中所选邮件”时，Orra 会先问“要替换你的草稿吗？”，点按“替换草稿”才会替换。点按“解释”后，先显示解释，然后是草稿，邮件本身在后面的“邮件原文”下面。点按“重新解释”旁边的“隐藏解释”，会先显示邮件本身，草稿在它下面，在你关闭窗口之前每封邮件都这样显示，点按“显示解释”可以让解释回来。“解释”和“重新解释”会显示它们生成的解释。如果没有整理模型，点按“解释”后会有一行说明，旁边的“打开‘项目’设置…”可以前往下载。如果整理模型在你的 Mac 上但无法载入，这一行也会说明，旁边有“重新载入”。超过 16 MB 的邮件“项目”不会读取，读取超过 90 天的邮件，“项目”会删除保存的文字。这两种邮件都会有一行说明原因，“解释”按钮不可用，请在“邮件”中阅读。解释包括：
  - **警告**，比如读者看不到的文字、与“项目”已知的某个域名相似但并不相同的发件人域名，或者邮件里有链接。Orra 的检查只看字面，所以关于密码或付款的警告只表示邮件提到了它们，并不表示邮件在向你索要。Orra 自己检查出的警告在你点按“解释”之前也会显示。
  - **邮件要点**，邮件说了哪些事。每个要点都附有标出出处的标签，没有出处的要点会写明“未提供来源”。文件的标签会在 Orra 里显示随解释保存的摘录和页码，附件的标签显示模型读取的那部分内容。“在模型读取前删去的内容”中列出的行仍留在保存的摘录里，但模型并没有读到它们。以前邮件的标签会在窗口里显示那封邮件，点按上方的“返回上一封邮件”可以回去。不会在 Orra 之外打开任何东西。如果某个附件属于“项目”能读取的类型却没能读取，比如“邮件”还没有下载的 PDF，要点下面会有一行说明。
  - **本次解释的项目文件**，收在“邮件要点”下面，标出文件数量。展开后，会列出本次解释时“项目”把摘录交给模型的每个项目文件：文件名、它在所属项目文件夹中的位置、“解释中已引用”或“解释中未引用”，以及加入的原因：“通过搜索找到”，或在搜索找到的摘录少于三段时，“项目里最新的文件之一，因搜索结果较少而加入”。每段摘录最多约 800 个字符，所以较长的文件不会整个交给模型。“解释中未引用”不代表模型没有参考这个文件。点按“第 2 页”或“已保存的摘录”，可以在 Orra 里查看那段摘录。文件所在的文件夹已不在项目中时，会显示“现已不在项目的文件夹中”。文件所在的项目文件夹无法访问时，比如在没有连接的磁盘上，会显示“它所在的项目文件夹现在无法访问”。“编辑项目…”可以更改项目的文件夹，更改会在索引完成后，从下一次“重新解释”起生效。没有归入项目的邮件会显示“归入项目”。Orra 0.6.1 之前的解释不会写明文件加入的原因。
  - **回复前需确认**，只有你能决定的问题，或者显示“没有发现需要你决定的事”。模型没有写完某一部分时，那一部分会说明，点按“重新解释”可以再试一次。
- **草稿。** 邮件需要回复时，后面会附上一份草稿，使用邮件的语言，中文或英文。“项目”判断为其他语言（例如日文）的邮件没有草稿。你发出的邮件、你后来在往来中回复过的邮件，以及来自邮件列表或机器的邮件，都不需要回复。草稿需要核对，请逐行阅读。Orra 会删去链接、声称某件事已经办好或以助手口吻说话的句子，以及回复给项目以外的人时涉及的项目资料，并标出星期不对的日期和没有出处的金额。回答检查会说明草稿回答了邮件中的几个问题，比如“对方问了 3 件事，你的草稿回答了 2 件”，全部回复时还会列出会收到回复的项目以外的人。你可以像编辑普通文字一样编辑草稿。Orra 会保存你输入的内容，关闭窗口后也会保留，保存好后草稿下面会显示“已保存在这台 Mac 上”。“语气”可以把它改写得“正式”“亲切”或“坚定”，“以中文显示”或“以英文显示”会在旁边显示它的译文。
- **修改草稿，也可以用说的。** 在草稿下面的框里写下要怎么改，比如“更正式一点，价格不变，交期改到 11 月 22 日”，然后点按“修改草稿”。新版本会高亮显示改动，“撤销修改”可以恢复修改前的草稿，包括你输入的内容，以后打开的窗口里也可以。“取消修改”可以停止正在进行的修改，草稿保持原样。修改需要等待时，比如你正在听写，下面会有一行说明原因，这时“拷贝”会拷贝当前的草稿。光标在这个框里时，说话键说出的话会直接进入框里，不经过剪贴板，你说完草稿就会修改。如果想先看看说出的内容，再自己点按“修改草稿”，请在“设置 → 项目”里关闭“说完就修改草稿”。在草稿里，翻译键的用法和在其他 App 里一样。
- **回复。** 点按“在‘邮件’中打开回复”，或者在邮件发给了多人时点按“全部回复”，“邮件”会打开带有引文和你签名的回复窗口，草稿会放到剪贴板上，“邮件”会切换到最前面。在那里按 Command V，检查回复后由你自己发送。“拷贝”只把草稿放到剪贴板上。这里没有“发送”按钮，Orra 从不发送邮件。和听写的文字一样，草稿只留在这台 Mac 的剪贴板上。
- **听写优先。** 你听写时、实时字幕运行时、Mac 内存不足时，以及在内存小于 24 GB 的 Mac 上载入了“为对方朗读译文”的语音时，“项目”会暂停使用模型，邮件列表下面会有一行说明原因。窗口关闭时，新邮件只按规则归类，其余的会在你再次打开窗口后由模型归类。如果只有“项目”需要载入整理模型，也会等听写结束后再载入。
- **关闭和删除。** 在设置里关闭“项目”时，Orra 会问你保留它保存的内容供下次使用，还是删除。在项目页面或项目的快捷菜单里点按“移除项目…”，会删除一个项目及其索引、邮件和草稿。在“设置 → 项目”里点按“删除‘项目’的所有数据…”，会删除“项目”保存的所有内容，包括你选择的邮箱。“保存在这台 Mac 上”显示它们占用多少空间。“邮件”里的邮件和你文件夹中的文件都保持原样。在“项目”里归入、编辑和删除，只会改动它保存在这台 Mac 上的数据，不会改动“邮件” App 里的邮件。“项目”唯一会请“邮件”做的改动，是在你点按“在‘邮件’中打开回复”或“全部回复”时打开一个新的回复窗口。“邮件”可能会像对待其他回复一样，把它存到草稿箱里。“项目”把邮件的文字和解释保留到读取后 90 天，把草稿和你在其中输入的内容保留到最后一次修改后 30 天，但不会比邮件的文字保留得更久。草稿删除后，解释仍会保留，点按“重新解释”可以获得新的草稿。“设置 → 项目”的“数据”部分也写明了这些期限。它在启动时以及打开期间每天一次删除超过期限的内容，所以“项目”关闭期间保留的内容，会一直保存到你再次打开它或删除为止。详见 [privacy.zh-CN.md](privacy.zh-CN.md)。
