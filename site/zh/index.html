Orra

说出来，
就写好了。

在任何 App 里听写和翻译，全部在你的 Mac 上完成。

下载 Mac 版

版本 0.3.0 需要搭载 Apple 芯片、macOS 15.6 或更高版本的 Mac，以及大约 3 GB 的可用空间。

照你说话的样子，
写成文字。

个人词库

把常用的名字和术语加进来，Orra 会按你的写法输出。

自我学习

听写后改正一个听错的词，Orra 会把它加入个人词库。默认关闭，打开后才会学习。

中英混合

说中文、说英文，或者在一句话里中英混说都可以。

中英翻译

说中文得到英文，说英文得到中文，都在你的 Mac 上完成。

隐私

你说的话，留在你的 Mac 上。

只有第一次下载 Orra 和模型时需要联网。之后，只有在你允许检查更新时，Orra 才会联网。其他一切都在你的 Mac 上完成，Orra 从不保存你的录音和说过的话。

打开“自我学习”后，Orra 也只保存词对。详情见 README。

开源

Orra 用 Swift 和 SwiftUI 编写，以 MIT 许可证发布。你可以阅读源代码、自己构建，或者帮忙改进它。

  • GitHub 上的源代码
  • 所有版本

发现了问题，或者想要什么功能？在 Orra 的菜单里选择“报告问题…”，或者在 GitHub 上告诉我们。
